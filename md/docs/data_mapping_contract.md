# 字段与可用性契约（实施要求）

所有实际映射写入本地 configs/data.local.yaml，不使用本包的 null 直接训练。

每个字段登记：来源文件及哈希、真实列名、内部语义名、dtype、单位、空值含义、event_time、available_at 规则、业务键、是否预测时可知、字典文件/工作表/行或官方答疑位置。

目标的 available_at 与历史特征的 available_at 分别登记。堵口时间只是候选可用性依据，存在报送滞后时须采用实际可用时间；不能把“最终表现在有该字段”推为“开铁时已经知道”。

已确认样本主表列来自 README：sample_id、tap_no、spout_no、reference_time；训练另有 tap_iron、tap_time_len。公共表字段的英文拼写尚未获知，禁止从中文说明猜英文列名。

冲突优先规则必须可追溯，原始数据只读；完全相同重复可以记录后去重，业务键相同但数值冲突需停止相关源。spout_no 缺失类别 token 检查命名碰撞；样本 ID 始终按字符串读取。

特征启用由 AI 依据字典确定，不等待用户逐字段批准。未确认的可选字段禁用，目标/主键/关键时间口径未知则阻塞真实验证。禁用清单随 feature_manifest 保存，不能无声更换数据口径。
