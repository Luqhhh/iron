# 候选的平台迁移证据记录

这是候选评审记录，不是新的训练协议、数值晋级门或平台分数预测器。使用时在具体阶段评估前冻结计算方法；平台反馈前保存本卡及排程理由，反馈后另行追加，保留当时判断。缺失项写明“未验证”和具体原因，不能以工程通过代替模型质量证据。

| 项目 | 必填内容 |
|---|---|
| 身份与参照 | 候选配方、权重、源码/运行/OOF身份；参照候选与包摘要；平台分数来源 |
| 原科学资格 | 各完整split增量、原门槛及未通过条件；开发选择、四seed晋级、人工探索分别记录 |
| 样本组成敏感性 | 322行配对抽样的固定方法、各split分布、逐行改善与贡献集中；明确不是平台成功概率 |
| 输入差异 | 冻结的无目标分布诊断；权重估计方法与ESS；未做时说明，不将加权结果自动升级为平台预测 |
| 发布迁移 | 原折与全量训练方法/选轮/初始化是否匹配；有全量状态时，在同查询上检查改变量；未全量拟合时明确未验证，不为填卡自动重训 |
| 平台机制证据 | 相关已测方向、相同或不同参照、正负反例；固定配方失败与整个家族分开 |
| G0 | 数据和源码/模型身份、隔离、冷推理、原字段字符串、包审计；与质量结论分开 |
| 排程判断 | 是否值得一个平台信息问题、为什么优先于其他候选、失败后改变什么判断；不能仅复述本地均值排序 |
| 预测边界 | 未解释因素；不得提供未经校准的成功概率或“当前分数+本地增益” |
| 后续反馈 | 用户原始回传、候选/包绑定、来源、相对参照增量；是否改变原假说，不改写旧卡 |

不能把SiLU本次已知负分当作本卡有效的证据。应以后续预先记录的判断与真实反馈考察它是否改善决策；数量少、主动筛选的平台样本也不能直接估算总体误筛率。旧SAM时间反例继续保留，任何新增稳健性指标均不得单独否决所有本地负收益探索。
