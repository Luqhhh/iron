# 本地到平台的迁移诊断（2026-10-04）

用户在 SiLU 回传后要求“尝试解决这个问题”，恢复针对本地筛选失真的工作。参照为用户回传、未独立核验的 DE3_IRON_EMA_MEAN3_Q100=96.3979；最近里程碑96.4，登记目标96.45。原暂停记录、SiLU两开发split与平台负收益、四seed门及所有历史失败决定保留。

本阶段先回答能检验的问题，不从已有平台反馈拟合新评分器。固定 SiLU A100/A20 两个原配方，A20仅作原候选对照，不安排平台测试。平台回传已知，故本轮属于事后机制诊断；结果不能算前瞻验证成功。

## 冻结问题与计算

1. **联合输入分布。** 仅官方复赛2754训练输入、322测试输入，排除ID和目标。使用21数值特征及铁口1/2独热。MMD采用池化输入均值/标准差（与域标签无关、仅用于分布检验），固定三个高斯核带宽为正平方距离中位数的平方根乘0.5/1/2，核等权平均，999次固定样本数置换，报告无偏MMD²、右尾Monte Carlo p值。池化缩放和带宽在置换下不变；非显著不证明同分布，显著不证明条件目标分布不变。
2. **输入相似度重加权敏感性。** 域标签只表示训练/测试来源，固定五折交叉拟合 Logistic 和浅层 HistGradientBoosting，各5次，共10次。Logistic缩放仅在域训练折拟合；不输入真实目标或sample_id。按各域训练折先验校正测试来源概率得到密度比，固定截断[0.2,5]；保存未截断范围、ESS、AUC/log loss及两套加权WMAPE增益。两方法全部报告、不按平台吻合度选方法。它们是估计权重下的诊断，条件目标分布不变和密度比估计准确均未证明，不能冒称无偏平台预测。目标模型OOF不变，跨split只汇总标量。
3. **同一测试输入上的重训改变量。** 两split×五折×三训练seed×ReLU/SiLU，共60原refit，加三seed×ReLU/SiLU全量6原refit，共66。核验原checkpoint、训练ID摘要和原OOF/全量预测冷回读；再在相同322测试输入上推理。每个split内先平均三个初始化，分别报告五个fold改变量及五fold均值与全量改变量的余弦、符号一致率、偏置、RMS、差值；不跨split平均向量。五fold均值只为诊断方差，不能视为单个80%模型，也不推出其隐藏测试误差更小。原epoch/更新数配对保存。新推理禁止target fit和optimizer；所有查询移除目标。
4. **322行敏感性。** 对两个完整split、两原配方，固定10000次均匀及按官方测试真实铁口计数的无放回抽样，重算WMAPE分母，同split候选共享抽样。记录收益分位和转负频率、逐行收益及去除最大1%正贡献的描述性统计。它们只描述OOF行组成敏感性，不是平台失败概率、平台置信区间或训练数据删行方案。

## 判读与后续约束

不设事后晋级阈值，不改变原候选分级。联合分布差异、加权增益反转、全量改变量不稳定分别只能支持对应的后续假说；没有一个量单独证明失败原因。两个加权方法不一致时保留不确定性。不能用SiLU已知负反馈选择权重、分类器、组、带宽或新的A20包。

之后候选评审至少明确：完整原OOF与参照、平台机制依据、322行敏感性、原训练与全量改变量是否可迁移、G0身份，以及哪些风险仍未解释。没有上述证据时，应写明迁移未验证，不能把最大本地均值直接表述为平台最可能赢家。此为证据呈现要求，不新增自动数值否决门。正式晋级仍遵守四完整seed且每seed正、seed层配对LCB95>0及原阶段门槛。

方法依据：[Gretton等，MMD两样本检验](https://www.jmlr.org/papers/v13/gretton12a.html)；[Sugiyama等，协变量偏移下的重要性加权验证](https://www.jmlr.org/papers/v8/sugiyama07a.html)。本阶段估计权重和WMAPE比值的诊断不直接继承后者的无偏保证。
