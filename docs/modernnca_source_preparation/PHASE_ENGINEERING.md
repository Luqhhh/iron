# Complete paired execution and current reference binding

ModernNCA now has a paired partition executor, append-only fit ledger, complete
phase collector, unchanged promotion arithmetic and a current reference reader.
The author-default model and its fixed encoder control remain unchanged from
the checked partition implementation. This is partial G0 engineering evidence;
G1 remains unmeasured, with no official candidate fit or formal queue.

Each outer pair saves four fresh selector/refit states. Only LEARNED_ENCODER
performs optimization; FIXED_ENCODER remains identically initialized and frozen.
The executor reserves four estimator constructions/preprocessing fits and two
optimizer runs. Selection uses the same group-safe inner split and first strict
best calibration MAE, followed by fresh outer initialization/preprocessing.
The complete development phase requires20 pairs/80 estimators/40 optimizers,
with exact unit and event inventories and five-fold coverage within each seed.
Interrupted reservations remain consumed and cannot silently retry. Ledger
limits count fits; there is no elapsed-time limit or projected-time rejection.

The collector independently reads saved banks, parameters, preprocessing,
calibration histories and caller-held hashes. It checks matching initial states,
fresh-refit epochs, optimizer steps and reservation results, then assembles each
seed's OOF column separately. It does not fit, initialize or average across
split seeds. The fixed20% isolated blend and original development/confirmation
gates remain binding; candidate tiers do not authorize release.
