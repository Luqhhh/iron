# 预登记：训练日程与损失对齐筛选（2026-10-02）

## 背景

- 平台代表仍为用户回传、未独立核验的 `EMA_TIME_Q75 = 96.3920`，目标 96.45 差 0.0580。
- 同日样本量学习曲线（控制臂与已记录 `joint-joint_plr001` 逐位一致，最大差 0.0）显示：铁量已饱和（训练行 1102→2203，WMAPE 0.037962→0.037294），时长仍有轻微数据受限（0.040869→0.038538）。两者都表明继续在**同一训练日程**下加容量或加权重不会有大收益。
- 现有全部 q75 阶段配方（V7/V12/V36/EMA/Laplace/Gaussian/MAE 等）都用**常数学习率** AdamW、MSE 标准化损失、单一选中轮次 refit。余弦日程、warmup、以及"直接优化与评分同形的标准化 L1 损失"在本项目**未被系统测过**；这是当前证据下最有机制依据的未测轴。

## 假设

H1：常数学习率不是本数据/配方的最优日程；余弦衰减（或短 warmup + 余弦）在相同轮数预算下降低 OOF WMAPE。
H2：训练损失与评分口径不一致（MSE 对标准化目标 vs 评分用原始单位 L1 型 WMAPE），改用标准化 L1 训练可降低 WMAPE。

两者可独立成立；本阶段同时筛，但分别登记。

## 冻结设计

- 数据：`复赛_train/`（授权公开）21 特征 + `spout_no`；目标 `tap_iron`/`tap_time_len`；不读取受保护标签。
- 折：冻结折向量 `local/runs/round2-v2/comparison-r1/folds-{42,3407}.csv`。
- 骨架：`bf_tap_r2.v12_joint.JointRegressor` 的联合 TabM + PLR（`frequency=0.01`）结构、预处理、内层选轮协议全部不变；只改训练日程/损失。

- 阶段 2（确认）：阶段 1 中两折**同向**且平均优于 `CONTROL` 的前 2 个配置，在 `split_seed∈{42,3407}` × 5 折上重训 = **20 次正式拟合**；与已记录 incumbent 列（`joint-joint_plr001-s{seed}-f{fold}.npy`）逐折配对比较。
- 阶段 3（可选、零拟合）：若某配置在两 seed 均改善，则在四 seed（含 271828/314159）组合评审 npz 上做**增量融合**检验（只改该目标列、权重网格与既有嵌套协议一致），仍不改 incumbent。
- 控制闸门：`CONTROL` 臂在阶段 1 两折上与记录预测**逐位一致**（容差 1e-9），否则本阶段作废并保留失败证据。
- 预算上限：阶段 1 + 阶段 2 ≤ 42 次正式拟合；不做全量数据拟合、不生成包、不写桌面、不上传、不改任何历史门槛。
- 资源：单数值线程（OMP/OPENBLAS/MKL/NUMEXPR=1，torch 线程 1），worker ≤ 8，峰值内存门槛沿用 1536 MiB/worker；不设时间预算。
- 判读：阶段 2 要求两个完整 split seed 的平均 WMAPE 均改善且 seed 层配对方向一致；只有满足才进入阶段 3 与后续确认准备。任何单折改善不构成晋级。

## 不做的事

- 不改、不重训 incumbent 模型；不覆盖任何既有运行目录。
- 不把本地增益写成平台预测；不据此直接发布候选包。
- 不扩大到容量轴（V25 已关闭）或 EMA 轴（既有阶段已闭合）。
