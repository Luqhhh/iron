# SWA周期A20平台反馈后的优化分析

2026-10-02。仅分析；没有启动新训练、创建新科学运行目录或生成新提交包。当前已登记本分支参照Q75=96.3920；该分支回填不覆盖其他分支的平台记录。

SWA_CYCLE_TAIL_V1_A20平台为用户回传96.3899，未经独立核验，比固定父包Q75低0.0021。原两开发seed平均本地增量+0.0044873709244，四seed平均+0.002917856711，271828微负；这些历史结果及未正式晋级决定保留。原连续窗口SWA两开发seed平均+0.0044435780486，四seed也有负seed。因此既不能只看最早两个正seed，也不能用一个平台负反馈宣布SWA整体无效。

## 已证实的部署差异

周期CV开发10个refit的实际保存窗口：3状态1个、4状态3个、5状态6个；确认10个：1状态3个、3状态1个、5状态6个。全部20个中17个实际平均至少3个状态，窗口文件与metadata选轮逐项一致。此核对只读取已有状态与元数据，零推理、零拟合、零标签读取。

平台全量模型selection完整跑到240轮后选择100轮，freshrefit到100；唯一周期末状态为[100]。它严格遵循原latest min(5,available)规则，实际平均1个状态，不能称为5状态平均。交付时已明确披露。这不是封包违规，但说明平台成员与多数CV成员在实际平均数量上不同。

窗口差异是明确事实；“单状态导致平台下降”仍是假设。全量样本数、内层校准分区、选轮和初始化也会变化，当前实验不能分离它们的原因，更不能保证改动后达到96.4。

## 下一轮优先级

1. **优先让周期SWA真正进行多状态平均。** 单候选可考虑保持原学习率与采样规则，仅要求至少3个已完成周期末状态才进入选轮候选，即最早140轮。在原完整240轮选择中比较合格窗口，freshrefit保持选中轮数及相同平均规则。需重新冻结并进行配对开发，不能把旧全量模型擅自续训到140或追溯改变旧最优轮。强制较晚选轮也可能损失早期泛化，必须评估这一代价。此处是建议，不是已登记或已启动协议。
2. **减少单个初始化及内层切分的偶然性。** 在第一方向证明有价值后，考虑少量初始化的同split集成；每个成员独立选择与freshrefit，OOF矩阵仍在同一个split内闭合，不跨split平均向量。预先固定种子、集成数量和预算，不从平台分数反推最优初始化。不同内层切分的稳定选轮也可作为独立后续问题，避免与第一方向同时改动而无法解释收益。
3. **保留原连续10epoch窗口作为平台机制对照。** 它仍是与周期方案不同的明确方向，尤其最早两个seed平均+0.00444，但四seed未通过正式门、尚无该全量配方的平台成绩。若后续安排平台探索，可用同父Q75、同A20、同固定铁量比较；不自动封包，也不把两开发seed收益称为确认通过。

本次暂不优先继续扫MAE、目标权重、窗口长度和同轨迹后期加权。现有TIME_SELECT、TIME_MAE、MAE_WARMUP、CYCLE_TIME_WEIGHT及LAST5等完整记录未明显胜过各自原控制；预测平均与参数平均的差别也很小。队友最新公开反馈中，LAPLACE_FIXED_A20及SEPARATE_MAE_IRON_A20也出现本地正、平台负，进一步说明本地筛选不等于平台成绩，但两个不同目标配方不能直接解释本次SWA时长失败。来源：origin/codex/strong-component-regularization的78b1380及其公开交付说明；不复制其私有模型或扩展其训练授权。

## 同一个已交付member的权重

在铁量固定、预测只沿(1−a)*Q75+a*同一member线性变化、平台确实使用固定样本的WMAPE线性计分时，绝对误差关于a为凸函数，分数为凹函数。a=0为96.3920、a=.2为96.3899，因而a>.2的同方向外推不应作为超过父包的路线；这只是同一member的条件结论，不适用于新训练模型或其他评分方式。四位小数舍入不会改变这两个点的负斜率。a在0与.2之间是否存在更优点仍未知，不以这两个分数推出它必然有提升。因此先改模型与实际平均机制，比盲目增大现有member权重更有信息量。

后续若使用既有四个split进行设计，应标明观察后探索；多split复用官方同一批样本不构成四个独立新数据集。所有正式本地门及历史分类保持；平台探索与正式晋级分别登记。没有新增训练授权、预算消耗、定时任务或平台上传。
