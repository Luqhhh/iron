# optimization-v0.29：冻结森林的 OOB 叶响应估计

本阶段是独立优化阶段，基于 `optimization-v0.28-fixed-equal-blends@00acbdf`。`6b40b55` 是 v0.28 算法提交；后续 `00acbdf` 只登记了平台反馈与发布状态，故 v0.29 从后者分支以保留完整证据。

父方案为用户回传 83.2936 的 `V28I_CB_QRF_EQUAL_BLEND`。两个候选在任何新反馈前同时冻结：

- A `V29I_OOB_LEAF_QRF_BLEND`：固定 v0.27 铁量森林，只以每棵树的 OOB 同叶原始训练行估计响应；空 OOB 叶回退该树同一完整叶。新 QRF 铁量与原 V26A 完整铁量端点继续各占 1/2，时长逐字符串复制 V28I。
- B `V29T_OOB_LEAF_QRF_TIME`：固定 v0.26 A 时长森林，以相同 OOB 叶协议替换响应估计；随后重放原 v0.15 支持度 gate 和 V21 的 25% 收缩，铁量逐字符串复制 V28I。

OOB 身份只从恢复后的 sklearn 1.8 `estimators_samples_` 读取。每棵树的 draw 长度、位置范围、节点唯一 in-bag 数与 bootstrap 加权数均须和树结构核对。每个 OOB 原始位置只计一次，不按 bootstrap 重数加权；每棵树仍贡献相同总质量。若某叶没有 OOB 行，只使用该树同一完整叶，不借其他叶、不丢树、不新增阈值。

本阶段新增森林、预处理器和校准拟合均为 0；派生 14 份 typed NPZ/JSON OOB 附件。开发沿用 06–11 六个 cutoff，最终沿用 2,754 行和 `2024-12-01 01:44:00+08:00`。原 210/213 列、训练顺序、响应、模型文件和树结构必须不变。

离线主口径为 origin 宏平均，pooled exposure 独立报告；参照为 V28I、V26A、V21、V1。G0 工程、G1 已消费历史质量、平台用户反馈分别登记。两份包各占一次平台预算，固定 A→B；不生成第三个组合，不自动上传、写桌面或公开推送。

冷审计恢复原模型、响应与附件，重建 bootstrap/叶成员证书，并覆盖全量、反序、分块、子集与单样本。将 OOB 成员替回全部原叶成员时必须精确复现原 QRF 端点。任何来源、未来信息、身份、数值、冷推理或 fit 拦截失败均阻断平台包。
