## 3. DE3：新增训练轨迹，不挑幸运 seed

### 3.1 不变项

铁量：0.5*V36_iron + 0.5*V12_joint_iron。
时长：0.2*V36_time + 0.3*N0048_time + 0.5*V7_periodic_time。

只替换铁量 V12 联合组件或时长 V7 周期组件；另一个目标和其他权重不动。沿用原生 float32、预处理、原始特征、16 个内部成员、损失、优化器和 native epoch/refit 规则。联合组件仍训练两个目标，只替换其铁量输出。

### 3.2 新变量

训练种子预先固定为 [42, 104729, 130363]。三个完整网络分别初始化、优化与早停，各自内部 TabM 结构不变。固定算术平均：f_DE3=(f_42+f_104729+f_130363)/3。

这里不改变 outer split seed、不改变 inner split 分区身份。不要把模型训练 seed 同时传给划分器；两个随机性必须分开。不得只提交最好的成员、筛选子集或拟合种子权重。不把现有单折 seed1042 诊断当作完整成员或确认集。

允许复用 seed42 原生 BASE 的20个完整单元，前提是 source、runtime、输入行、标签、预处理、训练分区和预测身份全部一致；不一致时拒绝复用，而非冒充零成本。新增种子必须从头拟合，不能通过重置输出头伪装成独立完整网络。

### 3.3 第一队列预算

开发覆盖：2 outer split seeds ×5 folds ×2目标组件 ×2新增训练种子=40个外层成员单元。
每单元内层选epoch一次、外层重训一次，合计80次新增候选拟合。20个旧seed42单元核验复用，不重复计作新增训练。

不再以两折粗筛进行质量排序。先完成两划分五折覆盖。合成测试只用于实现正确性和资源准入，不用于选择模型参数。四worker是执行上限，不是跨两队列并行授权。

### 3.4 真正需要计量的量

对每个目标、每个outer split分别计算完整OOF WMAPE。先在同一outer split/fold内平均训练seed，禁止先平均不同outer split的预测再评分。

设p_m为每个训练seed替换后的完整目标预测，p_0为现役预测，p_bar为等权平均：

D = 50/sum(y) * [mean_m sum_i |y_i-p_mi| - sum_i |y_i-p_bar_i|] >= 0。

净收益 = 平均成员相对现役的分数增量 + D。

D是绝对误差相互抵消的收益。D非负不代表净收益为正；成员若整体更差，平均仍可能输给现役。不要用均值分数替代平均预测的分数，也不要把低相关直接当作晋级条件。

附带 ensemble_gain_audit.py 验证这条恒等式、样本对齐和完整fold覆盖。它不验证原始训练谱系，输出明确带 provenance_verified=false；正式验收还需仓库原有hash/训练行身份审计。

### 3.5 晋级与停止

沿用当前机制准入：两开发划分均正、平均单目标完整包增量 >=0.01、严格优于原生BASE，才进入现有确认程序。0<均值<0.01保存为小收益，不消耗确认/平台预算，不改称失败为成功。

确认使用原有指定划分和同协议参照，报告四划分同号、既有LCB与96.25工作门槛；这些是工程决策规则，不构成四份独立样本或严格控制自适应选择错误率的证明。

K=3不通过就停止这个规格；不自动扩到8/16个seed、不逐seed挑选。通过后也先确认与平台测量，再考虑新增集成预算。确认阶段的成员拟合、基座工厂拟合与内部selector/refit分别登记，避免隐藏成本或重复计数。

## 4. E-COMPOSE：用最终部署预测选择epoch

### 4.1 可检验的协议差别

当前原生铁量联合网络按两个标准化目标平均MAE选epoch，时长网络按单组件MAE选epoch。最终部署却使用r(x)+0.5*f_e(x)。单组件最优epoch不必是这条最终预测的最优epoch；这只是待测缺口，不是已确认提分原因。

在同一条原生训练轨迹、同一候选checkpoint集合上，比较：

- E-NATIVE：原生选择规则，必须重放现役组件。
- E-TARGET：仅按当前待替换目标的组件MAE选epoch；铁量必须有此对照，以区分“改为铁量优先”和“最终组合优先”。时长下它与原生规则在候选集合相同且缩放为正时等价。
- E-COMPOSE：按内层校准集上 r_i+0.5*f_e(x_i) 的目标MAE选epoch。

公式：e*=argmin_e sum_{i in C}|y_i-r_i-0.5*f_e(x_i)|。铁量r=.5*V36；时长r=.2*V36+.3*N0048。

固定候选epoch集合为该次原生selector实际访问过的所有epoch；原生停止规则和240上限不变。三个选择器观察同一轨迹，不延长训练以追逐新指标。相同误差取最早epoch。此实验只测试既有轨迹里的检查点选择；不声称覆盖原生停止后的最优epoch。

选择后从头在完整outer-training上按选定epoch重训，保持现行native refit语义。已存在、可严格核验的相同refit可复用；不能因训练epoch接近而直接复用。

### 4.2 必须防住的内层泄漏

outer训练集分为A（拟合）和C（校准），outer评估集为Q。

选择epoch时，候选网络只在A训练；r(x)中的V36/N0048也只能在A及其更内层分区训练。它们在C上必须是真实样本外预测。

禁止拿“在整个outer训练集A+C拟合的现役基座”在C上预测，再用它选epoch。即使Q仍未见，这也已经污染了内层选择。

定好epoch后，才允许在A+C重训候选与外层参照，最终只在Q评价。跨fold、跨split缓存只有训练行哈希完全一致才可复用。

### 4.3 成本与对照

不混入SAM、EMA、Mixup、学习率改变、权重搜索、残差训练或延长epoch。先恢复已有checkpoint和合法内层reference的身份。

若原生每epoch预测/状态未保存，允许新建selector重放而不修改旧run。开发最多20个原生selector轨迹；新选定epoch的refit、内层reference工厂及内部组件拟合另行计数。两种目标在相同A/C分区可共享合法reference。

缺少合法内层r预测时先做资源准入，不把这一方向描述为零fit。不能因成本高改用污染的预测。

在本轮开始前，将E-TARGET与E-COMPOSE都登记为可晋级候选，每目标最多选一个；不得事后将对照追认为候选。E-COMPOSE必须同时比较现役和E-TARGET；只优于现役却不优于E-TARGET，不能归因于“最终组合感知”。若铁量仅E-TARGET有效，则将其记录为铁量优先的epoch选择收益。候选晋级沿用完整两划分和原门槛。是否晋级与机制解释分别记录。
