## 判读

- 硬树的**残差相关只有 0.93–0.96**，明显低于 TabM 家族内部的 0.98–0.99——这是本项目历史上"分散化成分"的特征（N-0048 当时 ρ=0.888）。
- 但它的**单独精度比 incumbent 差 3.3%–8.6%**，超过能换取正权重的范围：诚实留一选权在四组里三组选 0，唯一非零的一组（铁量、由 fold 0 选出 w=0.25）在留出折上损失 0.0065 分。
- 按预登记升级判据（时长精度比 ≤1.15 **且**增量融合为正），精度条件满足、融合条件不满足 → **关闭 GLOBAL 臂，不扩大预算、不自动改臂或调参**。这也关闭了仓库内最后一个"从未在官方数据上训练过"的模型类。
- 结论限定于该冻结配置（GLOBAL、1024×5、dropout 0.2、250 轮）。"硬树家族整体无用"不由此推断，但没有新的机制证据前不重开。
