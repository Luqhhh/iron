## 0. 一句话

V5 用**一个**大容量 N 家族成员把时长列换掉（α=0.2）就换来平台 **+0.0409**；而**铁量列从未试过容量杠杆**——V3.6 采样器把 `iron_capacity` 固定为 `small`（`build_N_trials`），铁量列只有 16 个 `small` 网络候选，其 N 成员权重仅 `0.036`、留一贡献 `−0.0003`（装饰性）。本轮把同一机制搬到铁量列，并把时长列的候选空间按“结构互不重复”重新筛一遍。

## 1. 为什么是这一轮（V5 的新事实，全部已实测）

| 事实 | 数值 | 对本轮的含义 |
|---|---|---|
| 获胜成员签名 | `v36-s1-N-0048`：`raw_tabm` / `large` / `mse_adam`，ρ=0.888、精度比 1.07、α=0.20 | 目标签名：**精度损失很小但相关性明显低** |
| 本地 → 平台 | 本地 `+0.00975` → 平台 `+0.0409`（**4.19×**） | 本地**不能**预报幅度，只能定方向与排序 |
| 平台分辨率 | 纯 seed 扰动只移动 `0.0005` | 平台足够细，真实效应看得见 |
| 转移误差 | 本候选 `+0.031`，**且此前由对照导出的“≈0.005”已撤回** | 不设“本地增益 × 常数 = 平台增益”的判据 |
| 兄弟重复 | `N-0048/0049/0050/0051` 是同一结构容量的四种训练设置，两两残差相关 **0.979–0.998** | **同族内的 seed / loss 多样性不产生独立成员**，必须按结构去重 |
| 现有池 | 两列都已榨干（时长列上限 `+0.0098`；铁量列最佳附加成员 `+0.0015`） | 必须新拟合，不再搜池 |

## 2. 目标与成功判据

- **主目标**：为 `tap_iron` 列产出**通过四 split seed 规则**的新成员。
- **次目标**：为 `tap_time_len` 列产出**与 `N-0048` 不重复**（互相关 ≤0.95）的第二个成员。
- **成功判据**：至少 1 个候选被四 seed 规则准入（≥4 seed、seed 级配对 LCB95>0、所有参与 seed 同为正），并能生成合规的单列替换包。
- **不是判据**：本地幅度、平台幅度预测。本轮**明确不预测平台得分**。
- 现行平台最佳：`V5_TIME_N0048_Q20 = 96.3143`（用户回传）；本轮目标是改进它。

## 4. 签名与准入规则（冻结）

| 阶段 | ρ ≤ | 精度比 ≤ | 其他 |
|---|---:|---:|---|
| Stage A（folds 0/1，seed 42） | 0.95 | 1.25 | 嵌套 2 折投影增益 > 0 |
| Stage B（5 折，seed 42/3407） | 0.95 | **1.15** | ≥8/10 折为正 |

**互不重复约束（本轮新增，直接来自 V5 的兄弟重复教训）**：同一目标选中的候选之间，**每个“结构×容量”族至多 1 个**，且两两残差相关 **≤0.95**；Stage A 与 Stage B 各检查一次。

## 5. 阶段与 stop rules

- **Stage A**：对 S1（零拟合）按上表筛选，并按结构×容量去重，取每个目标最多 6 个进入 Stage B。
- **Stage B**：对入选者补完整五折（seed 42/3407）。**Stage B 只是筛选，不能准入**（只有 2 个 seed）。
- **Stage C（四 seed 规则）**：对每个目标最多 2 个候选，在派生 seed `7777`、`12011` 上复现。**基座列复用 V5 已缓存的 `replication-r1/seed-{seed}/fold-*.npz`（身份哈希校验），只重拟候选**——这把 Stage C 的成本减半。准入 = ≥4 seed、seed 级配对 LCB95>0、所有参与 seed 同为正；折级仅作描述（`descriptive_only`）。
- **Stage D**：最多 1 个单列替换包；未改列**逐字节**透传父包；α 取全 seed 网格最优；必须通过回读校验与冷推理检查。
- **stop rules**（任一触发即停止并记录，不绕过）：
  1. Stage A 无准入候选 → 停止，**不拟合** S2；
  2. Stage B 无“均值为正且 ≥8/10 折为正”的候选 → 不进 Stage C；
  3. Stage C 无准入 → 停止，不封包；
  4. 任何阈值不得在执行中放松。

## 6. 预算（用 V5 实测标定）

V5 实测单折耗时（时长列 `raw_tabm`）：`small` 13–22 s，`medium` 55–87 s，`large` **253–561 s**。

| 阶段 | 拟合预算 |
|---|---|
| Stage A | **0** |
| Stage B | ≤6 试次/目标 × 2 seed × 5 折 = **≤60 slot/目标，≤120 slot 合计** |
| Stage C | ≤2 候选 × 2 派生 seed × 5 折 = **≤20 候选 slot**（基座复用缓存） |
| Stage D | 1 次全量拟合 |
| 墙钟上限 | **3 小时**（16 workers；超出即停止并记录，不静默超支） |

主导成本是铁量 `raw_tabm|large`：单试次 2 seed × 5 折 ≈ 4,000 CPU-秒。
