- V3-D004：旧残差暂不声称恢复精确拟合样本。新校准要求唯一 sample_id、
  预测训练/历史冻结时间、标签可用时间、来源与外层样本身份。
- V3-D005：F-C/F-D 未满足输入/字段口径前置条件，保留 BLOCKED；不得替换成
  未注册候选。合成测试不能解除真实数据授权要求。
- V3-D006：同外层样本比较得 E12-raw J=0.17171342055719652、E12-CVcal
  J=0.17258611678486493。全局固定 C_ref=E12-raw，不逐格选参照。
- V3-D007：15 配置初筛、四个单目标配置晋级、两个固定目标组合与 F-A/F-B
  已完成。被评价的四个候选均未通过新门槛，不替换 E16。不追加权重/残差微调。
  新模型校准、可选特征交叉未运行，其潜在效果仍未知。
- V3-D008：本次交付到开发对照与结果审阅；OPT-10 尚缺完整组合 lifecycle
  和统一发布实现，不能据单目标 bundle 测试请求真实保护访问，也不能声称全量交付。
- V3-D009（下一批结果前登记）：用户要求无新平台包则继续优化。完成两种已
  晋级模型的时序校准比较，以及一次 F-B×CatBoost 交叉（raw/CVcal 配对）。
  F-B 相对 E09 有正增量，CatBoost 是已跑的新模型中 J 更好的完整组合；
  F-A 未改善 E09，暂不交叉。不新增参数、目标混合或常数搜索。
  特征不变的模型复用经身份校验的内部选轮数；F-B 交叉重新执行同一内部选轮数算法。
  完整 16 单元与现有 C_ref 比较，新门槛不变。登记文件为 followup.yaml。

  字段支持同字段可见事件差值。以 REMAINING_FEATURE_REVIEW.md 和版本化
  features_remaining.yaml 解除 D005 的前置阻塞；不改写旧配置或旧状态。
  F-C 仅显式读取三列元数据，排除同时间批次；F-D 不假设持续生效状态或单位。
  两项各自与冻结 E09 独立对照，沿用全部 16 单元、C_ref 和原门槛。
  不读取保护目标，不新增模型配置、目标组合或权重搜索。
