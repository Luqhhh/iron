# 铁量强度与 seed 平均曲线（零拟合）预登记

日期：2026-10-05。规范：`configs/iron_strength_curve/SPEC.json`。实施：`scripts/iron_strength_curve.py`。参照 `DE3_IRON_EMA_MEAN3_Q100 = 96.3979`，目标 96.45。

## 动机

额度筛选复核（`docs/slot_screen/RESULTS.md`）的结论是：平台上只有"非扩张型、继续做方差缩减"的改动赢过，而扩张型改动 10/10 下降。同时，两个自然实验中**铁量改动是唯一被重复验证的机制**——同一铁量改变向量在两个不同起点分别得到 +0.0022 与 +0.0023（差 0.0001），而时长改动在同一条件下是 +0.0168 与 +0.0025。

incumbent 的铁量列来自 DE3：`V12_iron + 0.5 × (mean(3 seeds) − V12_iron)`。这个 0.5 是此前用户指定发布时固定的放大系数，从未在本地按曲线复核过。DE3 开发运行把**每个 seed 的逐折预测**都存了下来，因此"放大系数"和"平均几个 seed"两条轴都可以零拟合重新测量。

## 冻结的定义

- 源：`local/runs/independent-ensemble-checkpoints-20260929/development-DE3`（split 42/3407 × 5 fold，每单元含 `seed_42`=V12 原生单元、`seed_104729`、`seed_130363`）。
- 标签：`local/runs/de3-independent-batches-20261004/development-r1/oof-s{42,3407}.npz` 的 `actual[:,0]`（复赛训练标签，已被原运行使用）。
- 放大曲线：`iron(q) = V12_iron + q × (mean(3 seeds) − V12_iron)`，`q ∈ {0, 0.25, 0.5, 0.75, 1.0, 1.25}`，逐折与合并的 WMAPE。
- seed 曲线：1/2/3 个 seed 的全部组合均值。
- 指标换算：单列 WMAPE 变化 ΔW 对应总分 `50×ΔW`。

## 假设与判读

- **H1**：incumbent 的 q=0.5 已是局部最优（曲线在 0.5 附近取最小）。
- **H2**：三个 seed 的平均已到平台期（2→3 的边际收益为负或接近零）。
- 两条曲线都可能只反映这两个 split 的噪声；本阶段只给描述性证据，**不构成四 seed 正式晋级**，也不预报平台分数。
- q=1.0 落在 `iron_strength_bound_20261004` 已独立复核的条件平台上界（96.40025）覆盖的区间 [0.5, 1.0] 内，因此任何 q≤1.0 的平台增益都被该上界限制。

零拟合、零标签新增读取（只用已被原运行使用过的训练标签重算已记录预测）、零新包、零桌面写入、零上传；单进程单数值线程。
