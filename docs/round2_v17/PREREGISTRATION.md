等权 WMAPE 在当前非截断区间中，对两目标误差具有可加性。因此在三个来源确实使用同一隐藏评测集合、原始列保持不变的条件下：

`S_B = 96.3526 + 96.3519 - 96.3366 = 96.3679`。

若每个回传值与精确分值偏差不超过 0.0001，组合算术误差界不超过 0.0003。这不是模型预测误差的置信区间，也不是新的平台成绩。

## 2. V17-B0：先固定两列组合参照，不做权重搜索

定义 `B0_I = V12 原铁量列`，`B0_T = V7 原时长列`。

审计输入必须是三个精确原包，SHA-256：

- V12：`a1c205a6722da3976a12e258458b649967c7c25130a2c55d840c5ecb2a1dc669`
- V7：`4382523c7bd688974f87eab2f42502bf8f54b2b330008b36e797ae7672490299`
- A35：`b4e1fc2d1287a213e9d88d1c30a7420ecc222235fcc6b7191e341dfd16924b06`

验证 322 个唯一 ID、原顺序和列结构一致；V12 时长字符串等于 A35 时长字符串；V7 铁量字符串等于 A35 铁量字符串；所有预测有限且非负。新列逐字段复制，禁止重算、平均、重校准或改变小数精度。旧原包禁止覆盖。

附带 `compose_v12_v7.py` 用于执行上述审计。默认只写审计报告；只有显式传入 `--output-zip` 才生成新组合包。脚本从不上传，也不估计账户剩余额度。仓库最后记录的单次剩余额度已经被 V7 回传计入消耗，不据此推断之后日期是否刷新。

B0 的本地参照必须从同一 split seed、同一 fold、同一训练排除集合的 A35、V12、V7 缓存重建。铁量、时长使用各自发布时的固定 0.5 槽位：

`B0_I = 0.5*A35_I + 0.5*f_V12_I`

`B0_T = 0.5*A35_T + 0.5*f_V7_T`

实际本地分数由行级预测按全量 OOF 分母重新计算；不相加不同报告的折均值、池化值或不同配方的分数。

## 3. 不重跑的路线

V10 MAE/SmoothL1、V11 分位数表征、V13 单输出 PLE 修复、V14 联合 PLE、V15 专家门控、V16 序列稀疏掩码均不作为本轮主路线。原因分别为确认失败、没有超过当前参照，或者增量过小且不稳定。

这不证明整个模型家族永远无效，只意味着不应重复同一已关闭配方，或换成旧 A35 参照重新声称获得增益。也不恢复密集 alpha 扫描、样本 ID 特征、外部数据、外部预训练权重、测试标签反推或测试反馈驱动的逐点拟合。

## 4. J 线：铁量为主任务的联合训练

### 4.1 可检验的差异

V12 的固定 SPEC 使用两个标准化输出的等权逐头 MSE 训练，并以两个输出的平均标准化 MAE 选 epoch；发布只替换铁量。已有配置并没有针对“铁量主任务、时长辅助监督”选择 checkpoint。

这是真实的目标差异，不是已经证明存在的性能 bug。两个任务梯度是否有有害冲突、是否因此降低铁量表现，都需要测量，不能从“联合训练铁量改善、时长不改善”直接推出。

### 4.2 J1：仅改变停止准则

保留 V12 `joint_plr001` 的全部架构、损失、初始化、batch、优化器和训练预算，只把 inner epoch selection 改为铁量 raw MAE（同一验证集上与铁量 WMAPE 等价）。时长仍参加每个训练 batch 的原等权 MSE。

使用训练子集拟合预处理和目标缩放；epoch 选完后，以新初始化和全 outer-training 部分重训。outer 验证标签不得参与 early stopping、梯度诊断阈值或预处理。

J1 用于回答“旧的两个任务折中 checkpoint 是否妨碍铁量”。它是 J2 的配对控制，不扫描额外损失权重或学习率。

### 4.3 J2：只投影与铁量冲突的辅助梯度

相对 J1，仅改变共享参数的更新。令 `g_I`、`g_T` 是铁量与时长的逐头 MSE 对共享参数的梯度。

当 `dot(g_I,g_T)<0` 且 `||g_I||²` 足够大时，使用：

`g_T_safe = g_T - dot(g_T,g_I)/||g_I||² * g_I`

否则使用原 `g_T`。共享梯度为 `0.5*(g_I+g_T_safe)`；乘 0.5 保持无冲突时与原等权平均损失相同的尺度。

这是受 PCGrad 启发的**不对称辅助梯度投影**，不是未经修改的标准对称 PCGrad。只修改共享嵌入、主干及共享适配参数；目标私有输出参数保留原有目标对应梯度和损失系数。零范数情况不做投影。

保留 TabM 的逐子模型/逐目标监督，不能先把 K 个子模型预测平均再算训练 MSE；否则改变了另一个机制。

记录共享梯度余弦、冲突频率、两任务梯度范数、投影前后差异、两任务验证轨迹以及选择 epoch。这些是机制诊断，不是看过 outer 结果后新建的晋级门槛。投影只改变一阶原始梯度，尤其在 AdamW 下不保证每一步铁量损失单调改善，也不保证泛化收益。

对照关系：J1 vs 原 V12 测停止准则；J2 vs J1 测辅助投影；所有最终候选必须另外胜过 B0。

## 5. P 线：固定总容量的双频段周期表征

已有 V7 结果支持周期编码方向，但不证明下一种表征必然有效。本轮测试“一种编码中同时保留两种尺度”，而不是把单一频率参数从 0.01 密集扫描到 0.1。

设计两个对称分支，每分支 8 个周期频率、8 维投影输出，拼接后总嵌入仍为 16 维。两个分支都有独立可训练的周期参数和投影，其他结构固定。只对原方案中已有的数值特征应用编码；类别、ID、缺失值处理保持原契约。

固定两种配方：

- P-LL：两支频率初始化尺度均为 0.01，作为同结构控制。
- P-LH：两支初始化尺度分别为 0.01 和 0.1，作为双尺度候选。

两个分支的频率仍可训练，所以“低/高”指初始化机制，不承诺整个训练期保持严格不相交频带。记录最终频谱与分支激活，判断两支是否实际上退化为相同表征。P-LL 与 P-LH 参数量必须完全一致，并另行报告它们与历史单分支的参数量差异；不得把容量变化冒充频段效应。

铁量使用 V12 联合输出主干与 J1 的铁量停止准则；时长使用 V7 单输出主干和原时长停止准则。这样不强制两个目标服从同一个最优表示。

不同时加入 raw skip、额外 attention、更多层、扩宽网络或新正则；否则无法区分变化来源。只有独立通过的机制才在下一次预登记中合并。

## 6. 固定比较方法与预算

|注册单元|主评估目标|开发拟合数|
|---|---|---:|
|J1 主任务 epoch selection|铁量|10|
|J2 J1＋不对称辅助投影|铁量|10|
|P-LL 联合输出控制|铁量|10|
|P-LH 联合输出候选|铁量|10|
|P-LL 单输出控制|时长|10|
|P-LH 单输出候选|时长|10|

每个单元使用 split seeds 42/3407 的**完整五折**，共 60 次候选 outer fits。最多新增两次源实现控制回放（V12 与 V7）；缓存及历史已认证控制可用时不重复训练。不再用 folds 0/1 承担粗筛决策。

保持原 240 epoch 上限、patience 25 和既有训练参数；预算固定后不因负结果续跑至更高上限。记录 cap hit，不假装已完全收敛。运行环境沿用当前锁定版本，不为新方案自动升级历史依赖。

本轮主要比较**固定专家槽位替换**，不新建融合网格：

`candidate_I = 0.5*A35_I + 0.5*f_new_I`，时长固定 B0_T。

`candidate_T = 0.5*A35_T + 0.5*f_new_T`，铁量固定 B0_I。

每个候选都直接对比 B0；不把其相对 A35 的大幅收益冒充新增收益。独立“加入 25% 新专家”的探索不在本轮预算内，不能在槽位替换失败后追加扫描抢救。

统计采用每个完整 split 的 pooled WMAPE 和完整包分。折级分数只作诊断；不将折均值当成全数据指标。确认时保持开发冻结的槽位系数，不用其他 split 的同一批标签再次重选权重。

每目标最多一个候选进入 seeds 7777/12011 的完整五折确认，共最多 20 次追加 fits。开发控制计满时总上限为 82 次 outer fits；每次 inner 选 epoch 加 fresh refit 通常对应两次优化器运行，最多 164 次。若无候选通过开发门槛，则不消耗确认预算。

既有质量/发布约束保留：两完整开发 seed 正增益、四 split seed 均正、seed-level 配对 LCB 为正以及本地工作门槛 96.25。四个 split 重复使用同一批标签，LCB 只能视为切分稳定性指标，不能称为四份独立样本给出的真实 95% 泛化保证。V7/V12 的历史单包例外不自动变成本轮全局豁免。

本轮资源优先关注相对 B0 增益约 0.01 分以上的方向；冲击 96.4 的组合主候选希望累计达到约 +0.04 本地完整包分，为条件剩余差距 0.0321 留一定余量。它是搜索目标，不是新成功记录、不代表局部到平台按 1:1 转移，也不保证上线达到 96.4。
