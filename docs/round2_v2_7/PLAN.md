# V2.7：不同的平滑非线性模型

目标仍是寻找最高实际提分方案，而非仅完成已有包。上一目标回合产生新代码、130次CV回归器拟合及三个新包，属于进展；当前平台最高仍为用户回传B=96.0982，不能据本地表证明全局最优或平台最优。

树深、L2、Huber、二阶残差等尝试没有明显收益；旧K1的SVR为C=.1、epsilon=0，是旧阶段参数沿用。此阶段预先固定三个不同方向：JM1共享两目标的小型tanh MLP；KR1 RBF核Ridge；KS1 C=10、epsilon=.01的独立SVR。并登记各自与当前目标参照的50/50融合。不加入ID、新特征、测试拟合、目标链或额外种子，不扫描架构/核宽/惩罚系数。

所有标准化、类别编码、目标均值中心和尺度只由训练折拟合。MLP共享隐藏层；KernelRidge的两列是同一核矩阵下独立线性系统，并非目标相互作为输入。优化器不使用外层验证早停。收敛警告视为工程失败，不以exploration身份跳过。

固定两组原五折，共10个联合MLP、10个多输出核Ridge、20个独立SVR=40次CV拟合。已有两个最佳离线路线DJ铁量/AORD时长用来补充比较，正式分类仍按C2/B3和candidate-tiers-v1。模型需独立序列化回读、fold身份核对、原单位指标重算、反序/分批检查和推荐者2000次配对重采样。本阶段不全量训练、不动五个待测包；若找到有意义的新收益，另做审查后安排交付。重复开发切分不是独立确认。
