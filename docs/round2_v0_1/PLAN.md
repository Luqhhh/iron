入口固定为仓库 `复赛_train/`、`复赛_test/`。只允许 21 个数值特征和 `spout_no`，ID 仅用于连接和对齐。拒绝旧 ID、额外字段、重复 ID、不相同的 ID 集合及符号链接输入。保持样本主表顺序，连接显式使用 `validate="one_to_one"`。不读取初赛数据、权重、OOF、时间表或历史铁次，不恢复任何初赛时间或编号。

P1/P2 的训练入口（全新目录，不覆盖旧运行）：

```bash
uv sync --locked --python 3.12 --extra dev --extra round2
uv run --locked --python 3.12 --extra round2 python -m bf_tap_r2.cv \
  --output local/runs/round2-v0.1/p2-cv-r1
```

先验证P0摘要，随后冻结两组折与配置副本，再运行两组划分的中位数基线、50次主验证和20次复验。每目标按主验证汇总OOF WMAPE取前两名，平分按路线名排序；复验选择在读取复验结果前写盘。真实拟合开始/完成逐条追加到台账，每折即时保存模型及OOF，全部完成后生成汇总。断点失败保留证据，不自动重复拟合。缺失值策略为报错，当前完整数据不拟合填充器；S1使用均匀节点、常数外推、不含偏置列，Ridge固定SVD求解；CatBoost模型种子42、CPU四线程。以上实现选择在任何复赛拟合前冻结，不作参数扫描。

P1 主验证为 seed=42 的 5 折，复验为 seed=3407 的 5 折。两个目标共用划分；已确认的重复或同源组先保持整组，再平衡铁口。没有时间字段不代表样本独立同分布。标准化、填充、样条节点、选择和校准仅在当前训练折拟合。两种中位数基线不占平台名额。

P2 仅运行 `models.yaml` 中 L1/L2/S1/C1/C2 固定配置。主验证 50 次回归拟合，每目标最多两条候选复验合计 20 次，全量训练最多 4 次，总计上限 74 次。预处理和中位数另记。每条路线保留逐样本 OOF 和逐折结果；主指标必须拼接整轮 OOF 后计算 WMAPE 与等权 J。L2 在训练折按目标中位数归一化，预测恢复原单位。CatBoost 固定迭代，不利用外层验证折选停止位置。首轮不加标签裁剪、不扫参数、不恢复旧 QRF。

P3 独立选择两目标的基准与挑战者，先冻结 A=(I0,T0)、B=(I1,T0)、C=(I0,T1)。不为凑满候选保留明显更差路线。B 时长、C 铁量必须与 A 逐字符串一致，输入打乱后的预测按 ID 对齐应一致。封包回读严格检查 322 行、唯一准确 ID 集合、三列次序、有限预测，并恢复测试主表顺序。

P4 首日按 A、B、C 顺序使用名额；仅 B/C 均优于 A 时考虑 D=(I1,T1)。预留第五次，每日最多五次，处理中不重复上传。按已核实历史最高机制，无需仅因最近一次退化而重传最佳包。仅在确认线性评分映射、固定评测集合且无非线性截断后检查组合分数关系。初赛额度单独记账。

提交台账至少含赛段、候选、父候选、改变目标、代码 SHA、数据 SHA、模型配置、CSV SHA、提交时间、submission ID、分数、历史最高/最新/生效提交及保留/关闭决定。P0 不伪造空模型、OOF、折分配或提交台账。

首轮后只根据证据选择一个方向：少量交互、样条绝对误差版本、树模型单项对照、固定 50/50 融合或分布压力测试。跨目标预测链须使用对应训练范围内的 OOF 输入。所有方案都不继承初赛验证排名或门控。
