## 2. S1 固定槽位枚举

### 2.1 EBM 边界扩展：96

铁量 64 项：

- `max_bins ∈ {128, 256}`
- `min_samples_leaf ∈ {30, 60}`
- `interactions ∈ {10, 20, 40, 60}`
- `max_interaction_bins ∈ {32, 64}`
- `target_transform ∈ {log1p, mean}`
- 2×2×4×2×2 = 64

时长 32 项：

- 前四维与铁量相同
- `target_transform` 从 V3.3 完整开发 OOF 最佳时长 EBM 动态冻结；当前记录为 `log1p`
- 2×2×4×2 = 32

`interactions` 在实现和配置注释中明确为“自动交互项数量”，不是交互阶数；本批只使用二元交互，不增加三元和高阶项。

### 2.2 EBM→残差修正：32

每个目标 16 槽位：

- 基 EBM 中心：最多两个
  - 第一个：V3.3 完整开发 OOF 最强 EBM
  - 第二个：V3.3 完整开发 OOF 中结构不同的强者
  - 第二中心不存在时，槽位保留并写 `not_applicable`，不伪造模型，不拿其他中心顶替
- 坐标：`original_unit`, `log_unit`
- 修正器：
  - Ridge `alpha ∈ {10, 100}`
  - CatBoost `depth=2`, `l2_leaf_reg ∈ {30, 100}`，其余冻结
- 固定修正系数：`alpha=0.25`
- 16 = 2 中心 × 2 坐标 × 4 修正器

当前仓库的 V3.3 完整开发记录中，铁量存在两个结构不同中心；时长只记录到一个完整开发 EBM 中心。因此枚举槽位仍为 32，其中 8 个时长第二中心槽位标记为 `not_applicable`，实际可训练基础模型槽位为 136。

### 2.3 全局＋分铁口专家收缩：16

- 铁量父配方：`v31-s1-expr-iron-0018`, `v32-s1-iron_log_expression-0019`
- 时长父配方：`v31-s1-time-0021-0050`, `v32-s1-time_neighborhood-0126`
- 局部 L2 乘数：`{1.0, 3.0}`
- 收缩 `beta ∈ {0.25, 0.50}`
- 2 目标 × 2 父配方 × 2 正则 × 2 beta = 16
- 最小铁口样本数冻结为 200；未见或不足样本的铁口只用全局模型。
- 类别列保留方式固定为：全局和局部都保留 `spout_no` 类别列。

合计固定槽位：96 + 32 + 16 = 144。

## 3. EBM 内部 bag 协议

实现文件：`src/bf_tap_r2/v3_4_bags.py`。

`group-safe-bags-v1`：

1. 在当前训练部分内，按冻结的重复组与铁口分层 routine 生成五折。
2. 四个 EBM bags 分别用 fold 0/1/2/3 作为内部验证部分，其余为训练部分。
3. 传 `(4, n_samples)` 的 `int8` 矩阵：`+1` 训练，`-1` 内部验证。
4. 每个 bag 的训练和验证都非空。
5. 同一重复组不能跨 bag 的训练/验证边界。
6. fold 4 在本协议中始终进入训练部分，不作为任一 bag 的内部验证。

该协议与解释器版本 `interpret==0.6.10` 的源码路径一致；实现未把 EBM 拟合内的训练残差冒充 OOF 残差。

## 4. 包装器实现

实现文件：`src/bf_tap_r2/v3_4_models.py`。

- `V34EBMRegressor`：原始 21 数值特征＋`spout_no`；显式传递 bag 矩阵；支持 `mean/log1p` target 逆变换。
- `V34ResidualRegressor`：
  - 基础 EBM 在当前训练部分内用 group-safe 五折生成 OOF。
  - 所有修正器共享同一份 base OOF。
  - 支持原单位有符号残差和 log 坐标。
  - Ridge 的缩放/独热编码只在该训练部分拟合。
  - CatBoost 修正器使用有符号残差，不套用正目标 target transform。
  - `alpha=0` 直接返回基础 EBM 输出，不进入 log 分支。
  - 完成后在完整当前训练部分重训基础 EBM；推理 base 输出回原单位。
- `ShrunkSpoutRegressor`：
  - 全局 g 和局部 h_s 都逆变换回原单位后按 beta 组合。
  - `beta=0` 直接返回全局预测。
  - 局部样本不足或未见铁口回退全局。
- `V34Regressor`：按 `kind` 分派。

## 5. 受约束组合

实现文件：`src/bf_tap_r2/v3_4_composition.py`。

- `constrained_forward_select`：
  - 固定包含 L1 列；
  - 枚举最多两个新专家；
  - 新专家总权重 `≤ 0.5`；
  - 权重非负且总和为 1；
  - 空新专家集就是“不替换”的 L1 对照。
- `simple_mix_alphas` 和 `s0_rule_records`：
  - 实现 L1 + EBM、alpha∈{0.10, 0.25, 0.50} 的开发筛选原语；
  - 第二个 EBM 必须相对 L1 有实际正改善，否则不强行选择；
  - 当前只做目标级 WMAPE/包内 delta 计算原语，尚未接入真实 L1 OOF 数组。
- 权重和成员选择函数只接受调用方提供的开发/训练预测；调用方必须保证没有把外层验证标签传入学习部分。
