# EMA 按最终融合效果选轮：固定配对开发（2026-10-02）

目标96.45，参照为用户回传、未独立核验的Q75=96.3920。用户要求执行方案，且本目标持续授权已登记。本阶段只研究时长；网络、周期编码、MSE损失、初始化seed42、AdamW、batch256、EMA beta0.99、最大240epoch、patience25、min_delta1e-5和最终替换系数0.75全部复用原设置，不改原训练器或历史协议。

每个外层seed42/3407、fold0…4，训练池内用group-safe五折seed27001的fold0校准。复用原V27已经审计的完整父组件校准缓存，父模型只在其余四折拟合，排除所有校准及外层验证行/同特征组。预处理和目标标准化仅在本次selector训练行拟合；外层验证目标不进入选择。

这一共同校准切分与旧EMA的inner_seed42不同，**因此新控制臂不宣称逐位复现旧Q75**。两臂均在27001切分下共享同一条训练轨迹，唯一比较因素是选择指标，配对差异用于归因；另报控制臂及候选相对原Q75，明确共同切分变化的影响。两臂均保持原初始化与原refit过程。配置中的原`training.inner_seed42`仅作为历史设置保留，实际校准切分单独冻结为27001，不能误称仍使用42选轮。

- COMPONENT_MAE：按原float32标准化组件验证MAE选轮。
- FUSION_MAE：按`0.20*V36_cal+0.30*N0048_cal-0.25*V7_cal+0.75*EMA_epoch`的原单位MAE除以同一训练目标std选轮，保持min_delta量纲一致。该式等价于诚实的`Q75_cal+0.75*(EMA_epoch-EMA_old_cal)`，旧EMA抵消，无需读取外层OOF作为校准父预测。

两种patience状态独立模拟。某臂停止后冻结其最佳轮，不因另一臂继续训练而重选；相同轨迹只训练一次，直到两臂停止或240epoch。严格改善选首次最佳，不根据外层结果扩大轮数或修改权重。分别保留两种选择checkpoint，再分别重新初始化，在全外层训练池按选中epoch refit。更新步数、训练行数、EMA有效跨度记录作描述，本阶段不改跨度或进行步数缩放。
