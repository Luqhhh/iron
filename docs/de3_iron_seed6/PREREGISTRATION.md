# 铁量 seed 平均扩展（6 seed）预登记

日期：2026-10-05。规范：`configs/de3_iron_seed6/SPEC.json`。实施：`scripts/de3_iron_seed6.py`。参照 `DE3_IRON_EMA_MEAN3_Q100 = 96.3979`。用户指令："能提多少分就提多少分，继续"。

## 动机

额度筛选复核的结论是：平台上唯一反复为正的机制是**同族继续平均**，而铁量改动是其中复现最好的（同一铁量改变向量在两个起点分别实测 +0.0022、+0.0023）。当前铁量 = `V32_iron + 0.5*(mean(3 seeds) − J42)`。

已记录的逐 seed 预测给出 seed 平均曲线（合并 10 折）：

| seed 数 | 合并 WMAPE |
| ---: | ---: |
| 1 | 0.037708 |
| 2 | 0.037504 |
| 3 | 0.037445 |

用 `W(r) = A + c/r` 拟合（残差 ≤4.1e−6，相对 1e−4）：`A = 0.03730916`、`c = 0.00039756`。外推：**3→6 个 seed 的原始列增益 +0.0035 分，放大 0.5 后 +0.0017 分**。这是当前唯一有正期望的方向。

## 范围

- 新训练 seed：`999983, 1000003, 1000033`（与既有 `42, 104729, 130363` 不同）。
- 2 个 split seed（42、3407）× 5 折 × 3 个新 seed = **30 个估计器、60 次 optimizer**。
- 折划分直接取自记录的 `query_ids`（已验证与 `de3-independent-batches` 的 OOF 成员列逐值一致，差 0.0），不重新生成。
- 评估：`candidate = reference_iron + 0.5*(mean6 − mean3)`，铁量单列总分增益 `50×(WMAPE_incumbent − WMAPE_candidate)`。
- **门槛**：两个完整 split 均为正，才进入另行冻结的全量发布（3 次全量拟合、1 个包）。

## 边界

- 只有两个 split；四 seed 正式晋级需另行冻结确认。
- 预期效应是 1/r 外推，不是实测值，不写成平台成绩。
- 单 worker、单数值线程；无时间预算、无自动重试；零桌面写入、零上传。
