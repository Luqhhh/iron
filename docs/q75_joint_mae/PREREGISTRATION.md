# 两目标MAE的共享表征配对开发

2026-10-02，本96.45目标持续授权；用户要求充分探索后分配现有两个平台名额。参照EMA_TIME_Q75=96.3920为用户回传、未经独立核验。两个名额继续保留。

## 未覆盖问题及控制

旧V12/V14/V15联合网络使用标准化MSE；近期固定Laplace均为单目标，单目标铁量两开发切分一正一负。不能由此排除两目标MAE下的共享表征。队友公开cda8045的SWA_TIME_MAE_V1保留铁量MSE，仅改时长MAE，使用联合TabM和十epoch平均；本阶段不重复该轨迹、预算或确认。

[Caruana的多任务学习原始研究](https://doi.org/10.1023/A:1007379606734)支持把共享表征作为可检验的归纳偏置，不保证本任务正迁移。只测试一组明确配对：SHARED_MAE与SEPARATE_MAE。前者一个V33周期嵌入＋两层128 SiLU主干、两个位置head；后者两个独立V33主干。两者使用相同的两目标损失、联合选轮、初始每目标函数、batch顺序和优化设置。独立臂是本阶段机制控制，不列额外发布候选。原单目标模型独立选轮，不能冒充本阶段严格配对控制。

## 配方与预算

目标顺序铁量、时长，各自按相应训练分区均值/总体标准差标准化。损失为两个固定scale=.5 Laplace NLL之和，即mean_rows(2*abs(iron_error)+2*abs(time_error))；两目标显式系数相同。保留原V33周期频率.01、embedding8/frequencies4、float32预处理再转float64网络、seed42、AdamW .001/wd.0001、batch256、全参数梯度范数裁剪10、max240/patience30/min_delta1e-5。

初始化先按原GAUSS1构造网络。共享臂将原head第1行位置复制到第0行，第0/1行分别输出铁量/时长，第2行不用；独立臂深拷贝完整原网络，两臂都取原第1行。每个目标的初始位置函数逐位相同；独立臂无共享参数。保留不用的head，不额外初始化或挑seed。两臂参数量不同，共享梯度及全参数裁剪的行为也不同，因此结论只归因于这组完整训练配方，不声称隔离了参数数量或所有优化耦合。

两臂均使用inner27001分组五折held0，在F拟合预处理/目标统计，C上等权两目标stdMAE选择最早严格改善轮数；fresh初始化在外层训练池重训该轮数。标准化使用F统计，禁止C/query统计参与拟合。两个完整开发split42/3407 × 五折 × 两臂，共20双输出估计器、40optimizer、40selector/refit状态。此前已使用这些样本和切分，不称独立新数据集。Q75和原固定Laplace端点只读复用同split/ID/fold的已审计缓存，0参照fit，禁止跨split平均预测。

正式开发前，2754行全形状合成数据每臂一套selector/refit：2双输出估计器、4optimizer、4状态；两个目标均须优于训练中位数常数。禁止用合成结果挑臂。定向锁定Python3.12检查阻止Optimizer构造，预算0。源码冻结后不改；每阶段独立新目录，无自动重试、不覆盖失败证据。

单worker、OPENBLAS/OMP/MKL/NUMEXPR/Torch/interop均1；CPU固定依赖版本，uv --locked --no-sync。RSS≤1024MiB，独立新进程冷回读、反序、chunk37及独立NumPy全网络前向差≤1e-8；独立标量差≤1e-10。真实退出事件立即审计，运行中600秒观察，无时间预算。保护配置、数据、源码、缓存身份入冻结清单；复赛标签读取追加访问账本，不读取初赛2024年11月目标。

## 预先决定

候选仅SHARED_MAE_IRON_A20和SHARED_MAE_TIME_A20，每次只替换对应目标为.8*Q75+.2*member，另一目标不动。不生成双列组合，不调权重。完整覆盖后保留原candidate_tiers分类，跨目标最多一个确认候选。

确认准入要求两个开发seed各自对Q75严格正、共享相对独立控制两个seed各严格正；时长还须两个seed各自优于已就绪LAPLACE_FIXED_A20。合格者按平均Q75总分增量最大者选择，完全同分铁量优先。未满足的失败条件保留，不放宽门槛或挑目标/training seed。

本阶段确认、全量、包、桌面和上传均0。后续阶段另冻：正式晋级至少四个完整seed各正且seed层单侧t LCB95>0；发布还要求四seed对独立控制均正且LCB>0，时长另要求四seed对原Laplace均正且LCB>0。fold仅描述。本地收益不换算平台分数；探索分类不自动占用名额。
