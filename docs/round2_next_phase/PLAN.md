## 1. 目标与门槛

| 项 | 值 |
|---|---|
| 当前平台最佳（用户回传，未独立核验） | `V34_A` = **96.2684** |
| 当前本地同折参照 | `V34_A` outer 16061 = **96.199737** |
| 下一阶段平台目标 | **> 96.3** |
| 预登记本地工作门槛 | **≥ 96.25** |
| 本地冲刺 | ≥ 96.30 |

门槛算术（已复算）：

- 96.25 − 96.199737 = **+0.050263 分**
- 等价于 `Δ(W_I + W_T) = 0.00100526`
- 若**只改时长**：时长 WMAPE 需从 0.038150 降到 0.037145，即 **相对降低 2.635%**
- 若**只改铁量**：铁量 WMAPE 需从 0.037855 降到 0.036850，即 **相对降低 2.656%**

**结论：单侧的小幅改进即使真实，也未必够过门槛。** 现实路线是找到两个在相同开发切分上互补的改进，并确认组合后仍通过正式稳定性门槛。

## 2. 本机现状与硬约束

### 2.1 本机没有历史运行缓存

`local/runs/` 不存在。V2.x / V3.x / V3.4 的 OOF 库、成员池、ledger、DAG 全部留在跑实验的另一台机器上；只有公开的 docs / configs / src / tests 推到了 GitHub。

直接后果：

- `load_centers` / `sample_v34` 会抛异常；`load_oof_candidates` 会**静默返回空字典**
- **V3.4 的最终外层驱动脚本不在仓库里**：`constrained_forward_select`、`select_diverse_refinement` 在仓库内没有任何调用方（只有单元测试）
- 折协议可复现：`make_folds` 自冻结以来未改动，种子 42/3407/16061/18041 均可确定性重算

### 2.2 硬约束（不因本计划放松）

1. 指标、折协议、验收门槛冻结
2. 同一个 as-of 特征构建器用于训练 / 验证 / 预测
3. 绝不覆盖运行目录，绝不删除失败证据；ledger 一律 append-only
4. 试验身份必须含 source/config digest + 数据/折哈希 + trial hash
5. 新候选须有**至少两个完整开发切分为正**，才允许消耗新的最终外层种子
6. 未达本地门槛且未通过同协议外层验证的候选，不消耗平台测试额度
7. 用户自行上传；助手不自动上传、不自动封包
8. 模型、预测、报告、ledger、提交包不进 Git

### 2.3 关键方法学约束（本计划新增，先前记录未明确）

- **16061 是最终验证切分，其弱折只能作为已知风险记录，不得用于设计特征、残差专家或区域划分。** 新残差诊断、区域划分与特征筛选全部只从开发流程（42/3407）产生。
- **18041 是新的折切分，不是新的独立样本。** 结果应称为"新种子嵌套验证"，不得宣称为独立留出集验证。反复用同一批标签换种子，不能消除长期搜索的选择偏差。
- **残差专家必须完整嵌套。** 评估某个验证折时，基模型、残差模型、监督式特征筛选、专家选择与权重学习都必须在**该折的训练部分**完成。不得拿全量数据预生成的 OOF 残差切片直接训练外层专家——那些残差对应的基模型可能已经见过当前外层验证标签。跨目标预测作为输入同样受此约束。

## 3. 参照策略：0a / 0b 拆分

完整重建 V34_A（L0 → L1 → V3.4 全链）成本很高：原始 V3.4 一轮即为 4298s 粗筛 + 3917s 精筛，其上游的 V3/V3.1/V3.2/V3.3 规模更大（400 / 320 / 256 / 192 项），且**第一步是补写缺失的外层驱动，不是跑实验**。

因此把参照工作拆成两段，按需投入：

| 阶段 | 做什么 | 支撑什么 | 成本 |
|---|---|---|---|
| **0a** | 补写嵌套外层驱动 + 建**明确命名的新参照 `R0`**（同折协议，但成员池为自行重建，**不冒充 V34_A**） | **机制验证**：某方向是否有增量、是否互补 | 低 |
| **0b** | 完整重建 V34_A 同协议参照 | **晋级声明**：门槛 ≥96.25 是相对 V34_A 定义的，最终声明需要身份可比的参照 | 高 |

规则：

- 0a 的 `R0` 上得到的 **delta（相对增量）** 有意义，可直接用于机制筛选
- **不得**把 `R0` 的绝对分与 96.199737 相减，也不得把 `R0` 称为 V34_A
- 只有当某条路线逼近门槛时，才付出 0b 的成本把它坐实
- 复现状态与模型收益**分别报告**

## 4. 实验批次

所有路线先在 **42、3407 两个完整开发切分**上与同折参照比较；**不同时为正，就不动 18041**。

### 批次 0（先做，便宜）

**线性模型 OOF 验证。** 在 42/3407 折上跑 Ridge / 线性模型，报告 OOF WMAPE。

目的：检验"目标方差大部分可被线性解释"这一工作假设。若线性模型接近 3.8%，说明强主效应已吃掉大部分信号、交互特征的天花板低；若差距大，则交互与残差专家空间更大。

**该结果直接决定批次 1 与批次 2 的投入顺序，且不需要任何参照重建。**

### 批次 1：补齐时长 EBM 中心，做定向残差专家

- 背景：V3.3 只为时长记录了一个 EBM 中心，导致 V3.4 的 16 个时长残差槽位中 **8 个标 `not_applicable`**，是明确的覆盖缺口
- 但**空槽位只说明覆盖不足，不证明其中有可利用信号**；本批次是机制验证，不是预算
- 先补齐时长 EBM 中心，再看新专家是否与 V34_A 已用的时长残差互补
- 重点检验新专家是否修复**跨开发切分重复出现**的弱区域，而非只看开发均分
- **晋级条件**：两个完整开发切分都改善

### 批次 2：小批量对照——少量交互特征 vs 分铁口收缩修正

两个机制同批检验，由开发残差决定先后与取舍：

**(a) 残差引导的少量成对交互特征**

- 用开发 OOF 的**有符号残差与绝对残差**，检查主导特征、特征对、铁口及其交互
- 只保留 **42 与 3407 都出现、方向一致、覆盖样本足够**的模式
- 候选：`oxygen × pig`、`oxygen × air_volume`、压差各组成量之间的关系，以及这些关系是否随铁口变化
- **已有四个比值特征先作对照**，避免换名重复搜索
- EBM / 树本身已能表达部分非线性，新特征必须证明**增量**，不能只证明单模型好看

**(b) 分铁口收缩修正**

- 不扩大原有 16 槽位的笛卡尔网格
- 只测：共享主模型 + 每口对**低维残差项**做收缩；以及在明确特征区域内做平滑门控
- 要求**两个铁口分别报告 WMAPE、样本覆盖与最差口退化**
- 注意：每口约 1370 行，连续特征尾部容易被切得很稀；`spout_no` 边际相关小（铁量 −0.023 / 时长 +0.183），但不排除条件效应
- 原收缩专家 `v34-s1-global_spout_shrink-0136` 在 A 中占权重 0.094，而 A/B 平台仅差 0.0024 —— **这只说明组合器在开发数据上用了它，不等于可转移的增益**

**扩展条件**：哪一侧在两个开发切分都有增量，就扩展哪一侧。

### 批次 3：目标隔离与组合约束对照

**目标隔离作为默认评估方式**（它是控制风险的评估机制，不是新增信号）：

对每个新专家 `E_t`，预先固定三臂比较：

```
V34_A铁 + E_t时        （仅时长更新）
E_t铁  + V34_A时        （仅铁量更新）
E_t铁  + E_t时          （两侧都更新）
```

另保留完整参照对照。权重只从对应外层训练部分的内层 OOF 学，另一目标原样保留。允许在开发切分选择三臂之一，但**选定规则必须先冻结**，之后才运行新的外层种子。

**组合约束**：只做少数预注册对照（例如检查已选专家权重是否长期顶在 0.5 边界、第三个专家在两个开发切分是否均有独立残差收益）。目前没有证据表明"≤2 个专家 / 总权重 ≤0.5"是主要瓶颈；无正当理由不放宽。

**首轮不追加按样本动态切换的门控**，否则会引入另一层选择与验证成本。

### 批次 4：冻结并验证

- 冻结候选池、筛选次序、单列选择规则、组合权重学习流程
- 运行 **18041** 同协议外层验证，并与**在 18041 上重跑的参照**比较
- **不得拿 16061 的 96.199737 跨种子相减**
- 仍须满足正式折数门槛与最差铁口门槛

### 后续（前述方向不足时才投入）

**非对称跨目标预测输入。** 例如预测时长时加入"仅由特征预测出的铁量"及其与压差的低维交互；反向单独测试。训练阶段给第二层的铁量输入必须是**更内层的 OOF 预测**，不能放入真实铁量或同一样本的训练内预测。

两目标相关 0.543 只说明**存在共享信息的可能**，不保证增益；不同主导特征（铁量靠 `oxygen` 0.733，时长靠 `total_press_diff` 0.689）与 MultiRMSE 的单侧收益使非对称设计比直接扩大联合模型更合理。

## 5. 明确不做的事

以下路径**看似快捷但最容易产生刚好被本地-平台差异吞掉的"收益"**：

1. 根据 A / B 的 **0.0024 平台差**倒推专家的因果贡献
2. 在 2754 行上**全量扫描**比值、分箱、交叉项后挑最高 OOF
3. 用真实的另一目标、训练内预测、或 16061 弱折来训练回退规则
4. 因某方向"覆盖不足"就假定其中存在可利用信号并据此预算增益
5. 把 `R0` 的绝对分与 96.199737 相减
