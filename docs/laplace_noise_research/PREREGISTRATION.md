## 独立性、经验与机制

队友继续 SWA/EMA/ModernNCA/局部岭等方向，本聊天不重跑其优化。历史 V34/V35 测过高斯 CRPS 自然梯度树，延长到 3000 轮后仍无 B0 增量。因此**不宣称自然梯度树是新家族**，不靠增加其轮数重新包装。已检查公开文档和配置，未发现同规格 Laplace NLL 配方；队友未推送的研究仍可能重合。

独立问题：与固定全局噪声尺度的中位数树相比，同时学习条件尺度的 Laplace 对数评分树，能否改变模型在工况上的容量分配并为当前 Q75 增量融合带来收益？先验证实现，正式问句本阶段不回答。该机制不由无标签 MMD 阴性推导成立。

Laplace 的位置同时是中位数。固定尺度的 NLL 是 MAE 加常数，贴近原始绝对误差目标；可学习尺度将高误差工况与低误差工况区分。正面理由是可能学习不同的函数，而非优化旧预测权重。风险是异方差似然**并不等价于比赛 MAE**，可学习尺度可能掩盖位置误差；须保留 FIXED 控制，并在官方完整验证上测增量，不能只报告似然改善。

这是新具体配方，不是论文原创或严格复现 NGBoost 库；实现使用解析 Fisher，不复制官方示例的 Monte Carlo metric。依据：[NGBoost 论文](https://proceedings.mlr.press/v119/duan20a.html) 与 [官方 Laplace 开发示例](https://stanfordmlgroup.github.io/ngboost/5-dev.html)。

## 冻结模型

Y 只以拟合分区的中位数和标准差标准化（常量目标的标准差用 1）；X 仅以拟合分区均值/标准差变换，常量列用 1。输入是 21 数值列与固定 spout1/2 one-hot，共 23 列；类别也依此训练内变换，未知类别不在此阶段范围。

参数 (mu, log b)，初始 mu=0、b=标准化 Y 对训练中位数的平均绝对偏差（下限 exp(-6)）。NLL=log(2)+log b+abs(Y-mu)/b。普通梯度为 (sign(mu-Y)/b, 1-abs(mu-Y)/b)；推导的 Fisher=diag(1/b²,1)，交叉项 0，自然梯度 (b*sign(mu-Y), 1-abs(mu-Y)/b)。残差为 0 时 sign=0。测试以有限差分、Fisher 乘积等核验；Laplace 精确参数点的非光滑性如实保留。

FIXED 每轮只拟合位置梯度一棵树、b 保持训练初值；ADAPTIVE 分别拟合位置和尺度两棵树，不共享树结构。两臂 max_depth3、min_leaf20、squared_error 拟合自然梯度、树 seed42，500 轮、lr .05，按规格降序步长寻找第一个使**训练 NLL**不升的步（含 0）。尺度 log b 限 [-6,3] 是预定模型约束，不是封包时裁剪。最终预测为原始单位位置，不做预测裁剪、偏移或目标联动。

提供校准 MAE 选轮接口（含初始常量、平局取更早轮），参数更新和步长只看训练区；后续官方选择器与 fresh refit 须另行冻结。本工程固定 500 轮，无验证标签选轮、无超参搜索。

## 合成工程验收

固定 RNG seed961201：先生成 2754x21 独立标准正态 X，再生成独立 spout1/2，最后生成 Laplace(0,1) 噪声。Y=100+6*x0+4*sin(x1)+2*x2*x3+(.4*exp(.5*x4))*noise。前2204行训练、后550行 query，固定 one-hot 拼接。两臂各完整 fresh fit 一次，分别须优于训练中位数常量在 query 上的 MAE；**不要求 ADAPTIVE 胜 FIXED**，不按合成分数调配方。

保存 hash 绑定的可信本地模型、query 与预测、逐轮训练 NLL。独立新进程无重训练，完整／逆序／37 行分块回读预测须逐元素完全一致、尺度有限为正，拟合计数 FIXED500、ADAPTIVE1000。工程模型拟合2、树拟合1500，与未来正式科学拟合分开。失败证据保留，不自动重试。
