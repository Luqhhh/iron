# 预登记：K32 邻域二次单因素扫描（2026-10-02）

## 动机

阶段 1 的 16 个单因素配置中只有 `K32`（`tabm_k` 16→32）在两个目标、两个折上同向改善（铁量 −0.000436、时长 −0.000669），且四 seed 时长增量融合过门（+0.0046、LCB95 +0.0022）。阶段 1b 在 k=16 时的组合（余弦+L1、PLR 频率）在 k=32 上**无复利**，k=48/64/96 也不更好。

但阶段 1 的**其他**单因素都是在 k=16 下测的；K32 说明该模型在此数据上仍有未开发的容量/正则余量。因此在 **k=32 邻域**重做一次单因素扫描（坐标上升的第二步）。

## 冻结设计

- 骨架：V12 训练设置 + `tabm_k=32`；数据/折/协议与阶段 1 完全相同。
- 阶段 2a：`split_seed=42` fold 0/1，16 配置 × 2 折 = **32 次正式拟合**：

| id | 相对 K32 的改动 |
| --- | --- |
| `K32` | 无（对照） |
| `K32_DROP0` / `K32_DROP2` / `K32_DROP3` | dropout 0 / 0.2 / 0.3 |
| `K32_WD0` / `K32_WD1E3` | weight_decay 0 / 1e-3 |
| `K32_BATCH128` / `K32_BATCH512` | batch_size 128 / 512 |
| `K32_W128` / `K32_W384` | width 128 / 384 |
| `K32_B1` / `K32_B3` | blocks 1 / 3 |
| `K32_NFREQ32` / `K32_EMB32` | n_frequencies 32 / embedding_dim 32 |
| `K32_LONG` | max_epochs 400、patience 60 |
| `K32_LR3` | learning_rate 3e-3 |

- 阶段 2b：把 2a 中**两折同向且平均优于 K32** 的改动做一次组合检验（最多 4 个组合臂 × 2 折 = 8 次），确认是否有复利。
- 阶段 2c：胜者（或 K32）在 `split_seed∈{42,3407}` × 5 折确认（10 次）；若两 seed 均改善则再走四 seed（20 次，另行冻结）。
- 预算上限：32 + 8 + 10 = **50 次正式拟合**；无全量拟合、无包、无桌面、无上传。
- 资源：单数值线程、worker ≤ 6、峰值内存 1536 MiB/worker；不设时间预算。
- 判读：单折或单 seed 改善不构成晋级；本地增益不得写成平台预测。已关闭的轴（k>32、余弦+L1 叠加、PLR 频率叠加）不重开。

## 冻结后更正（2026-10-03，阶段 2a 之后）

阶段 2a 结果：**时长没有任何臂优于 K32**（全部 Δ≥0）；**铁量有两个两折同向改善的臂**：`K32_LR3`（lr 3e-3，−0.000431）与 `K32_DROP0`（dropout 0，−0.000329）。

因此阶段 2b 的臂固定为 K32 邻域内这两个方向的组合（含与余弦+L1 的组合），共 5 臂 × 2 折 = **10 次拟合**（原写"最多 8"，更正为 ≤12）：

| id | 改动（相对 K32） |
| --- | --- |
| `K32` | 对照 |
| `K32_LR3_DROP0` | lr 3e-3 + dropout 0 |
| `K32_LR3_COS_MAE` | lr 3e-3 + 余弦 + L1 |
| `K32_DROP0_COS_MAE` | dropout 0 + 余弦 + L1 |
| `K32_LR3_DROP0_COS_MAE` | 三者叠加 |

判据不变：两折同向且平均优于 K32 者进入 2c（两 seed × 5 折，10 次）。总预算 32 + 10 + 10 = 52。
