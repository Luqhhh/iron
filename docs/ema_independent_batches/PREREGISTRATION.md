# EMA 内部成员独立小批量开发

2026-10-04，96.45 持续优化授权内的新阶段。冻结参照为用户回传、未独立平台核验的 DE3_IRON_EMA_MEAN3_Q100=96.3979，差距0.0521不代表可达收益。用户本次明确还有三次提交额度；本阶段不预先消耗或推算额度，不写桌面、不由助手上传。

已核查旧EMA跨度、三到五训练seed、EMA32、SAM、dropout一致性、选轮、损失、初始化和残差记录：未发现内部16个TabM成员使用独立小批量排列的既有实验。该机制不同于增加整个网络的训练seed。已有EMA及mean3平台正收益提供方向依据，五成员和EMA32失败是相关反证，不保证本机制有效。BASE_MEAN3、旧硬树等信息问题保留；继续微调已测强度暂降优先级，不据局部历史试验宣布96.45不可达。

机制来自[TabM作者示例](https://github.com/yandex-research/tabm/blob/main/example.ipynb)的share_training_batches=False接口；本地tabm0.0.3支持三维输入。仅借用内部各成员不同训练样本的机制，不采用示例数据、预训练权重或示例中的测试集评估。我们的随机顺序由NumPy逐列无放回排列产生，不称完整论文复现。原每成员独立MSE损失不变，不改成预测均值的损失。

固定训练seed42/1042/2042，每个程序16个内部成员在每epoch各遍历本训练分区每行恰好一次；每列独立排列，B×K索引同时作用于特征、类别和目标，末尾短batch保留，禁止bootstrap漏行。初始化、dropout、EMA beta=.99、原AdamW、width256/blocks2/k16、batch256、标准化和周期特征保持。选择阶段只用内层训练拟合预处理，inner seed42/fold0按原EMA成员均值MAE选轮，max240/patience25/min_delta1e-5；fresh全外层T refit使用所选epoch，所有16头均值推理。新设置与每epoch排列摘要保存到原生状态。

split42/3407各完整五fold，所有30个新估计器、60次optimizer及60个新selector/refit状态完成并冷审计后才读取完整质量；不以fold0/1粗筛。原相同三个训练seed的30个EMA估计器、60个状态在新进程重新冷核对，原缓存身份不重命名。worker只接受已冻结本outer T训练帧与无标签query，复用原嵌套阶段的同分区输入，不跨split平均预测。

当前时长参照为B=V32+(mean(旧三EMA)-V7)，铁量为已冻结DE3原同split预测。固定候选顺序IBATCH_A100、IBATCH_A20，时长分别B+a*(mean(新三EMA)-mean(旧三EMA))，a=1/.2；不选择成员，不扫描更多权重。铁量不变，所以增量只来自时长；独立审计同时重算完整双目标分数。全量若另行发布，未改列须直接复制父包CSV原字符串。

两个完整开发split均正才取得另行冻结确认的准入，最多选一个，按均值增量大者、同分按上述顺序；candidate_tiers独立照原规则报告。正式晋级仍需至少四完整split、各正、seed层配对LCB95>0。本批不消耗确认seed。平台探索与正式晋级分开：结合完整本地反证、已有平台反馈、机制信息价值、工程状态决定，不以本地正负作为唯一依据，不因候选产生而填满三名额。

工程预算仅一个合成2204行、完整21数值特征/两类别、原模型形状的selector/refit程序，各至多2epoch、共2次optimizer；另有无optimizer的三维输入/头目标对齐、排列覆盖、隔离、固定配方、失败与预算测试。工程数据不参与质量结论。原训练器不改，独立模型及控制器在新worktree冻结；源码、配置、依赖、原始训练分区/缓存/模型/反馈、检查收据摘要在首次科学拟合前闭合。源文件发布前按当前分支upstream普通推送，私有模型和机器报告仅local。

锁定Python3.12及原CPU环境，导入前OPENBLAS/OMP/MKL/NUMEXPR=1，torch/interop=1；串行单worker，RSS1536MiB，600秒观察，真实完成立即审计。无时间预算、自动重试。独立新进程检查训练分区、预处理、选轮、原生step/optimizer计数、每头完整排列、源码/模型身份；完整batch冷预测精确相同，反序/37行分块误差≤.0005。最终新进程用标量math.fsum从所有成员重算配方和分数。失败/中断原目录保留，不改已冻结旧科学决定。
