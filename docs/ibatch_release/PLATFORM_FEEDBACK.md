## 结果判读

**`IBATCH_TIME_A20` 成为新的用户回传最佳 96.3987**，距 96.4 为 0.0013、距 96.45 为 0.0513。这是近阶段少见的**本地符号与平台符号一致**的候选：本地 +0.0004、平台 +0.0008。机制上它是"同族继续平均"——独立批量划分让三个 EMA 成员的训练批次互不相同，属于已被平台反复奖励的方向。

**`JOINT_IBATCH_IRON_A20` 下降 0.0015**，与铁量列已在局部最优的既有结论一致（全部 7 个已记录铁量方向均无实质增益）。该固定配方关闭，不再重试相近权重。

## 一条必须记录的负面证据：冻结额度门出现了假阴性

上传前记录的筛选证据（`docs/ibatch_release/RESULTS.md`）显示两个包**都未通过**冻结额度门：

- `IBATCH_TIME_A20`：slope **+0.00027**（判为扩张型）
- `JOINT_IBATCH_IRON_A20`：slope **+0.00081**（判为扩张型）

而实际结果是其中一个**上涨 0.0008 并刷新最佳**。也就是说，"非扩张才赢"这条来自 23 份回传的描述性规则，在本次对**赢家**给出了错误的否决。该规则此前已经明确登记为"未验证的前瞻假设、不得据此预报或关闭方向"，本次是它的第一个前瞻反例；原规则与历史决定保留，不追溯修改，但**后续排程不得再用 slope 符号单独否决候选**。

未验证泛函同样给两者负值（−0.00076 / −0.00228），再次确认它不能用于筛选。
