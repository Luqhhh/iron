## 2. 已实施：从边界声明到真实训练路径

新增`bf_tap_r2.row_nested_blend`，与历史`v5_resolution.nested_blend`分开，不改旧评分或门槛。
这是单个外层训练/评估单元的执行核心，尚非完整赛事运行器：

`外层T -> T内部各折新拟合/OOF -> 仅T标签选择候选和alpha -> T上新拟合 -> 无标签E预测 -> 单独评分`

- 选择/预测接口不接受E标签；评分是另一接口。所有标签必须按唯一sample_id索引，覆盖完全一致；打乱标签顺序仍按ID正确对齐。
- 模型输入帧只允许冻结21数值特征、铁口与ID元数据；真实目标和任意额外列直接拒绝。ID不允许作为模型特征，需要模型适配器审查保证。
- 外层ID重叠、跨边界重复特征组、内层拆散重复组在拟合前拒绝；重复组包括跨铁口的相同数值向量。
- 不接受已有全局OOF数组。每个内折参考/候选均在T内重新拟合；候选选择和alpha共同留在T内。
- 每次必须创建新估计器，拒绝实例复用。候选及权重网格在调用前冻结；精确平局优先只用参考，再按固定候选顺序和较小alpha。
- 启动前预留`内折数*(参考数1+候选数)+2`个fit调用预算；选择alpha0时省去候选外层重训。
- 所有预测有限、形状严格匹配，并在选权与预测处一致进行非负截断。返回内折/外层的训练与预测ID账本。

嵌套评价应隔离选择和评价，是[scikit-learn官方说明](https://scikit-learn.org/stable/auto_examples/model_selection/plot_nested_cross_validation_iris.html)
给出的原则。本实现用于补强当前流程，不把通用文档的偏差量套用到本赛事。

## 3. 实际合成验证与边界

29项新增测试通过，连同前轮8项诊断测试共37通过。覆盖无泄漏路径、评估标签变动不影响选权/预测、
训练和评分的ID对齐、重复组隔离、私带目标/全局OOF拒绝、预算不足零拟合、平局/候选顺序、
新实例要求和非有限预测拒绝。真实线性/均值模型合成探针包含两次选择/预测执行，
每次8个fit调用，合计16个合成调用，不是16个赛事模型。
只改变六个E标签时，候选、alpha、全部预测与训练账本完全不变，只有事后分数改变。
测试另执行两次探针，结果逐字段一致。合成分数不列为赛事提升。

这验证了新核心及合成适配器的路径，并没有证明任意Python回调安全。
模型工厂仍可通过闭包/文件访问偷读标签；进程内接口不是安全沙箱。实际适配器必须审查，
其插补、尺度、bins、early stop、目标变换均只能读取当次fit分区。
完整运行器还需预注册外层折/候选清单、身份哈希、拟合前追加账本与失败证据保留、冷审计。
当前单目标标签接口不直接承载V12联合监督；接入前须显式扩展训练标签合同，确保两个目标都只来自T，
不能通过闭包读取全量辅助目标。fit调用数也不等于优化器训练次数，需展开记录内层epoch选择/重训成本。

后续外层结果仍来自历史被探索过的数据，不能抹去此前自适应决策。多个seed是切分稳定性，
不是独立抽样数据；不得以新引擎名义重解释旧的四seed下界。
