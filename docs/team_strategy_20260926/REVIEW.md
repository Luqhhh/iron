## 3. 本次继续研究得到的新证据

### 3.1 跨 seed 选权不构成样本级独立验证

`src/bf_tap_r2/v5_resolution.py::nested_blend` 对每个 held seed，仍把完整 `y`
传给其他 seed 的 WMAPE 来选 alpha。两个 seed 的预测是在同一批样本上对齐的，所以 held
seed 某个评估折的标签仍进入选权。该函数的 “Held-out labels never enter the weight choice”
描述在样本级意义下不成立。V7 等调用该函数的结果仍有**切分重复稳定性**意义，不能据此宣称
完整选择流程具有独立外层验证。

本次直接调用原函数做合成反例：十行、两个 seed、五折，基准预测恒为 10，候选恒为 12，
alpha 仅 `[0, 1]`。只将 seed42/fold0 的两个评估标签由 10 改为 12，其余标签、折和预测
数组完全不变，seed42 的 alpha 从 **0 变为 1**。因此评估行标签确实影响该 seed 的选权。
这是选择层的标签依赖，**不证明基础模型的 OOF 训练直接包含自身留出标签**，也不量化任何真实候选的偏差。

另一个 seed 的完整 OOF 即使删除评估行本身，剩余行的预测模型也可能在训练时见过外层评估行。
严格方案须在外层训练行 T 内重建内层 OOF，不能仅对已存在的全数据 OOF 做行过滤。
新工具的 `audit_selection_boundary` 同时检查选权行与评估行不交叉、选权预测模型训练行均属于 T。
账本检查是来源声明验证，不替代对实际训练代码的审查。

反复优化验证指标可以造成选择偏差，且量级可达到模型之间的差异；这是降低候选自由度、
将整个选择流程放入外层评估的原因。[Cawley & Talbot, JMLR 2010](https://www.jmlr.org/papers/v11/cawley10a.html)

### 3.2 四 seed 是稳定性筛选，未增加四倍独立样本

`seed_level_summary` 用四个完整切分增量做 Student-t 下界。算术与历史门槛可保留，但它主要
描述同一批数据在不同划分下的变化；共用训练行、评估行和既往搜索历史会造成相关性。
7777/12011 已多轮使用，改一个 seed 也不会产生新的、从未用过的标签。
增加 seed 可以减少某些切分/训练随机性的影响，不能替代增加独立样本或样本级嵌套选择。
K-fold 误差相关会使忽略相关性的方差估计过小。[Bengio & Grandvalet, JMLR 2004](https://www.jmlr.org/papers/v5/grandvalet04a.html)

未来阶段继续执行历史四 seed 门槛，并追加样本级边界核验。行或真实分组的配对重采样可描述
冻结预测对样本组成的敏感性，但不能自动包含重训和整轮模型选择的不确定性。
在旧标签上新建嵌套流程也不能抹去此前的探索：应称为“冻结当前假设后的补充复核”，
最终未见样本能力仍要依靠平台或后续独立数据。

### 3.3 没有找到明显的输入特征分布偏移

对 21 个数值输入和铁口做固定五折 train/test 来源分类，ID 和目标完全排除。
分类预处理均在分类训练折拟合；两个预先固定的模型，没有根据结果调参：

| 本次量 | 测量结果 |
|---|---:|
| 线性来源分类 pooled OOF AUC | 0.481846 |
| 小型 HGB 来源分类 pooled OOF AUC | 0.520041 |
| 22 项 KS 经 Holm 校正后 p<0.05 的数量 | 0 |
| 最大单特征 KS 差异 | 0.070959，furnace_throat_temp |
| train / test 1号铁口占比 | 50.3268% / 50.9317% |
| 测试特征行与训练特征行哈希匹配 | 0 |
| 训练铁量与时长 Spearman 相关（描述性） | 0.545358 |

结论是**当前诊断未检出明显输入偏移**，不是证明 train/test 完全同分布。322 行样本和两个
有限分类器检出力有限，特征来源分类更不能排除 `P(y|x)` 改变。现在缺少把分布重加权升为
主线的证据；联合表示分享则有 V12 的实际增量和目标相关作背景，但相关本身不保证多任务训练有效。
本次诊断没有跨域调整赛事目标模型，没有重新开放历史关闭的 sample-reweighting 路线。

### 3.4 平台 alpha 曲线应使用绝对误差的形状，而非二次峰值外推

固定父包和端点列时，分数为 `S(alpha)=C-k*sum(abs(y-p0-alpha*(p1-p0)))`，
所以是**分段线性凹函数**。平台 0、0.05、0.20、0.35 四点的相邻割线斜率依次为
0.220000、0.199333、0.148667，符合凹性。

最后一段上升不证明 0.35 右侧仍上升，也不能识别 0.72 为峰值。
忽略四位回传舍入，0.35–1.00 区间的分数上界约为 **96.433233**：
`96.3366 + 0.1486667*(1-0.35)`。这个数学上界不是可达预测；实际最优也可能仍是 0.35。
现有四点不足以保证 96.35 或 96.4，也不足以宣布不可达。

已交付的 A45/A60/A72/A85/A100 可以补齐这条已验证方向的响应。优先索取其已有回传，
再决定是否需要局部夹逼；不要仅据二次拟合额外交付密集权重网格。
平台 best-kept 降低分数回退成本，但名额和自适应选择偏差仍存在。

## 4. 推荐策略与合理性

### P0：补反馈、统一事实入口

首先收回 V7 及已交付 alpha 包的候选名/得分/包身份。V7 方向既有最大的一项成熟时长增量，
又已完成交付，新增离线拟合成本为零。结果会直接决定时长基准及后续实验的增量参照。
当前始终以 A35=96.3366 为有回传的平台最佳；V7 是已交付待回传，V9 是本地候选。
未来维护者应把 README、queue 和当前状态统一，避免根据陈旧入口安排实验。

### P1：把样本级隔离作为下一阶段必备条件

冻结少量明确配方；对每个外层折分 T/E，在 T 内构建内层 OOF、选择 alpha/配方/epoch，
再在 T 上重训并只预测 E。T 内的全部基准和候选模型都不得见 E 的标签。
有资格复用的缓存必须逐模型证明训练行属于 T；现有跨 seed 全数据 OOF 不自动满足条件。
保留完整五折与四 seed 稳定性历史门槛，把输出区分为“历史规则通过”和“样本级边界通过”。
如果资源暂不足，固定 alpha 后复核只能作为较弱的补充，不应重新叫作完整选择流程的独立验证。

这种投入减少的是误选和虚增收益。它不承诺让分数上升，但会让后续大规模搜索更少浪费算力与名额。

### P2：优先补强 V12，并执行 V13 修复对照（9/26建议）

09-27结果更新：V12已交付；V13修复对照已结束且无可晋级增量，当前不再执行/追加这一组实验。

V12 铁量相对 V9 的四切分增量 +0.011627，相对 A35 为 +0.016088，明显大于此前损失/分位数微调；
联合监督分享表示有直接实验支持。最新团队确认已按原规则通过，但还需补充前述证据边界说明。
其96.226441开发包分仍低于历史96.25门槛，V7的单候选发布例外不自动适用V12。
后续团队已收到“授权这一个V12包”，另行冻结了A35铁量50%混合的单候选发布例外；不改变全局门槛。
此授权由团队已登记的工作负责执行，本研究工作区没有其私有附件，未重复执行拟合或生成包。
V13 的新价值来自**有直接梯度证据的实现缺陷**，而非重命名已经失败的配方。

用同一训练坐标，沿团队已有预算运行。V13的冻结主参照仍是V7/V9，不能追随V12结果回写；
后续团队已在完整结果出炉前声明V12相对增量诊断，原V7/V9选择规则保持不变；跟进这一补充结果，
防止把V12已经覆盖的收益再次算成新收益。这个诊断仍沿用历史跨seed选权，不能替代P1的样本级隔离。

官方包建议 PLE-B 使用 `activation=False`，数值嵌入也有独立研究支持，但它们不能证明本任务一定获益。
[作者实现说明](https://github.com/yandex-research/rtdl-num-embeddings/blob/main/package/README.md#piecewise-linear-encoding--embeddings)、
[数值嵌入论文](https://arxiv.org/abs/2203.05556)。

若 inactive control 也提升，应归因于标准化线性嵌入或训练程序；只有 repaired 相对 control 的 held-out
增量才能支持恢复非线性分支的解释。禁止把历史 N-0060 失败当作已测试正常工作的 PLE。

### P3：先单目标验证，再做准确组合

V7 先验证时长；铁量优先补强 V12，V9 保留为较小增量备选。各方向都相对明确父包单独评价。

尚未知的两个平台增量混加成预测。确认两个单列的实际平台收益后，再按原始字符串组合并冷审计。
本次没有执行新的发布、双列打包或平台上传。

### P4：控制边际收益低的搜索成本

暂缓在既有近重复成员池内反复堆叠、密集 alpha 和相似 loss/quantile 微调。
闭合结论仅适用于已测固定配方；有新机制证据时，重新开一个有限、可归因的受控实验。
较大的新方向、实现正确性和完整流程验证，应先于广泛增加参数组合。
神经模型从零训练，继续禁止外部预训练权重。每轮公开写明假设、对照、拟合上限和停止条件。

## 5. 统计谬误检查：11/11

| 类型 | 本次判断与限制 |
|---|---|
| Simpson's paradox | 有铁口分组；当前新候选附件不在本机，尚不能独立重算分组增益，应保留分组检查 |
| Ecological fallacy | 四切分结果不外推为每个样本均改善 |
| Berkson's paradox | 库只收已精筛成员会产生条件选择；库穷尽不等于所有模型穷尽 |
| Collider bias | 来源分类只用允许输入；本次未据目标或误差筛选样本，不作因果调整结论 |
| Base rate neglect | 来源分类报告 AUC，同时记录2754/322的比例，未以高多数类准确率声称偏移 |
| Regression to the mean | V10/V11 开发增量在确认中收缩，不把开发冠军直接认作稳定提升 |
| Survivorship bias | 失败和未通过门槛的阶段保留；不只汇报 V7/V9 的正结果 |
| Look-elsewhere effect | 多轮共用标签和平台反馈存在适应性；边际KS用Holm校正，候选搜索需要外层流程验证 |
| Garden of forking paths | 已有配方预算不事后修改；本次建议作为下一阶段，不回写旧门槛 |
| Correlation != causation | 目标相关及误差相关都是描述量；机制解释需要同程序消融 |
| Reverse causality | 联合监督不把任一真实目标当推理输入；没有时间字段不能提出时间因果结论 |
