## 3. 新的条件计算：组合与调权不能混为一谈

条件沿用[团队平台边界说明](../round2_v12/PLATFORM_BOUNDARIES.md)：同一隐藏样本与标签、
分列等权WMAPE、原始固定预测端点、无新后处理，每个回传分数误差不超过±0.0001。
本机没有原始提交预测数组，不能独立确认这些端点与回传归属。

直接复制原V12铁量A50、原V7时长A50的条件算术为
`96.3526 + 96.3519 - 96.3366 = 96.3679`，保守区间`[96.3676,96.3682]`。
这不是实际提交分数或保证，仍未达96.4；中心值距96.4为0.0321。
不得把这个平台算术差值当作新的本地准入阈值。反馈不授权生成组合包。

进一步，令S0、SI、ST分别为A35、V12铁量A50、V7时长A50的真实分数，
铁量和时长对各自固定成员的权重为a、b。单列未截零分数在仿射权重上凹，
因此a、b都在`[0.5,1]`时：

`S(a,b) <= 2a*SI + 2b*ST + (1-2a-2b)*S0`。

两项增量即使计入误差仍为正，故此上界在a=b=1最大。
取最保守回传误差，得到`2*96.3526+2*96.3519-3*96.3366+7*0.0001 = 96.3999`。
这是凹性割线延长的上界，不是猜测连续峰值；正的上界也覆盖最终零分截断。

| 固定端点范围 | 条件上界 |
|---|---:|
| V12铁量权重0.5–1，原V7时长A50固定 | 96.3844 |
| V12铁量与原V7时长成员权重均0.5–1 | 96.3999 |

第二个上界距离目标仅0.0001，**十分依赖精度假设**。若每分误差改为±0.0002，
上界变成96.4006，便不能排除达标。不能把96.3999说成赛事总体不可达。
权重低于0.5、新成员、更换训练端点、改变评价样本或后处理均不在此结论内。
原V7方向也不能与旧N-0048时长直线混同。

算术用Decimal及既有有理数割线工具独立重算一致；另构造40个双目标合成绝对误差曲线，
每列31个权重，38440次分数检查无越界，并核对分列加性。
合成检验不使用官方标签、不拟合模型，不能验证平台实现或实际端点。

   预处理、分箱、目标尺度、早停只能读取本次训练分区。禁止工厂闭包偷读全量辅助目标。
4. 冻结单个小候选池和等预算控制，把内层模型、候选选择、选权都留在T内，
   评估E仅用于事后评分；先完成五折覆盖，再按原四切分门槛确认。
   开始前展开真实训练成本并追加私有账本，保留失败产物和独立冷审计。
5. 只研究有明确新互补机制的方向，而非重复已否决配方或承诺调权补齐0.0474。
   候选价值仍是相对实际现有目标列的增量，不能只看单模型误差或装饰性机制活动。

平台反馈闭环这次已补齐，但平台收据、队友私有附件的本机复现、严格样本级真实训练接入、
对历史反复探索的偏差评估和新的可验证信息来源仍缺。没有额外数据证据，不能虚构时间特征。
