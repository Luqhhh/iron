# 预登记：样本量学习曲线与噪声底判定（2026-10-02）

本阶段回答一个决定后续路线的问题：当前最优成分的误差里，有多少是**可学习的函数残差**，有多少是**不可约噪声**。判定结果决定是否继续投入新模型，还是把剩余努力放到别的机制上。

## 背景与依据（冻结时）

- 平台代表仍为用户回传、未独立核验的 `EMA_TIME_Q75 = 96.3920`；目标 96.45 差 0.0580。本轮不产生平台分数。
- 同日零拟合证据（私有 `local/runs/q75-stack-review-20261002/`）：
  - 汇总库 199 个铁量列、209 个时长列（≥2 个完整 seed）；库内列与 Q75 的相关系数普遍 ≥0.995，残差相关 0.96–0.99。
  - 诚实嵌套线性叠加（四折拟合、留出折评分）相对 Q75 的时长增量均值仅 +0.005 至 +0.012 分，铁量 +0.003 分。
  - 事后（in-sample）最优 NNLS 上限：时长 0.0374/0.0373、铁量 0.0369/0.0371，相对 Q75 约 +0.04–0.05 分。
  - 嵌套全局/分桶残差校准全部为负（−0.0005 至 −0.0041 分）。
  - 残差形态接近高斯：铁量 `mean|r|/std = 0.775/0.776`（高斯 0.798）、时长 0.787/0.789；峰度 0.28–0.76；跨 seed 残差相关 0.98+。
- 上述都指向"接近噪声底"，但**没有直接测量**：库内模型都用了同样的 2754 行训练集，容量/正则轴的上限无法从库内推断。

## 假设

H1：误差主要由不可约噪声支配 → 训练集减半后 OOF 误差几乎不变（学习曲线平坦）。
H2：模型仍受数据/容量限制 → 训练集减半后 OOF 误差显著上升，说明增加有效容量或更好正则仍有余量。

## 冻结设计（必须先于任何新拟合写盘）

- 数据：`复赛_train/`（授权公开），特征 21 列 + `spout_no`，目标 `tap_iron`/`tap_time_len`；不读取任何受保护标签。
- 折：沿用冻结折向量 `local/runs/round2-v2/comparison-r1/folds-{42,3407}.csv`；本阶段只使用 `split_seed=42` 的 fold 0 与 fold 1，以及 `split_seed=3407` 的 fold 0 作第三人。
- 配方：incumbent 联合 TabM + PLR（`backbone=tabm, frequency=0.01`），训练设置完全取 `configs/round2_v12/SPEC.yaml` 的 `training` 段（width 256、blocks 2、k 16、dropout 0.1、AdamW lr 1e-3、wd 1e-4、batch 256、max_epochs 240、patience 25、inner 5 折选轮、按选中轮数在外层训练集上 fresh refit）。
- 唯一自变量：外层训练行数比例 `f ∈ {0.5, 0.75, 1.0}`。子样本按 `spout_no` 分层、用固定派生种子（`seed = split_seed*1000 + fold*10 + round(f*100)`）确定，**只用外层训练行**，评估行永不参与。
- `f=1.0` 臂是**控制臂**：其预测必须与已记录的 `local/runs/round2-v12-joint-tabm/development-r1/joint-joint_plr001-s{seed}-f{fold}.npy` 在容差 1e-9 内一致；不一致则本阶段作废并保留失败证据。
- 预算：3 单位（seed42-f0、seed42-f1、seed3407-f0）× 3 比例 = **9 次正式拟合**（每次 2 个 optimizer：内部选轮 + 外层 refit），控制臂 3 次包含在内；另计工程冒烟 0。单数值线程、峰值内存门槛沿用 1536 MiB。
- 资源：串行或最多 3 个 worker；OPENBLAS/OMP/MKL/NUMEXPR 线程固定为 1；不设时间预算。
- 评价：每个比例在每个单位上计算两目标的 WMAPE 与合成分 `100-50*(W_i+W_t)`；跨单位只汇总指标差，不跨单位平均预测向量。报告 `f` 的学习曲线斜率与"外推到无限数据"的粗略截距（仅作描述，不作平台预测）。
- 判读规则：若 `f=0.5` 与 `f=1.0` 的两单位平均合成分之差 < 0.02，则记为"接近噪声底"（H1）；若 > 0.05 记为"仍受数据限制"（H2）；中间记"部分数据受限"。任何结论只适用于本配方与本数据。
