4. **决定性数字：只改训练 seed（配方完全不变）就能移动 `-0.0050` 分（铁量）/`+0.0003` 分（时长）。** 这与多数候选的效应同量级——即**本地分辨率下无法把小于 ~0.005 的候选效应从 seed 噪声里分离出来**；`N-0048` 的 `+0.0097` 分是唯一明显高于该噪声底的本轮候选。

6. **`v36-s1-N-0048` 通过四 seed 复现（首个）**：`7777`/`12011` 派生 seed 上增益 `+0.0097`/`+0.0088`，seed 级 LCB95 `+0.0075`，4/4 为正；预期平台效应 `+0.005 ~ +0.015`（点估计 ≈+0.01），即 `96.278 ~ 96.288`，**可能刷新最佳但仍未达 96.3**。该候选预期本地完整包 `≈96.2135 < 96.25`，按现行门槛不自动生成候选包。
6. **因此本轮唯一交付的包是已声明的对照实验包 `V5_SEED_SWAP_S1000`**，用来把平台差分解为“seed 敏感度 + 平台分辨率”。验收目标仍为平台 > 96.3（用户原文目标 93.5 已保留在 SPEC 中，且早已被 96.2734 超过）。

### 3.1 晋级 ≠ 平台候选包（门槛算术）

冻结规则要求“本地完整包 ≥ 96.25”才消耗平台额度。本轮候选只改时长列：

```
V36 本地完整包          96.2038
+ 单列混合增益           +0.0097
= 预期本地完整包       ≈ 96.2135  <  96.25（本地工作门槛）
```

因此本轮结论是：**`v36-s1-N-0048` 进入 `candidate_pool`（首个通过独立 split seed 复现的候选），但未达平台验收门槛，不生成候选包**；唯一的平台提交仍是噪声底对照包。

其余候选（`+0.0019 ~ +0.0086` 分）与“只改训练 seed”的 `0.005` 分同量级或更小，按 stop 规则不消耗 Stage 2b 预算。

### 3.2 复现期修正的两处规则缺陷（已修并加测试）

1. **折级门槛是绝对计数**：`admit` 原先要求“≥8 格为正”，在 4 seed × 5 折 = 20 格时等于只需 40%。已改为按 SPEC 的 `8/10` **比例**（20 格需 16 格）。若不修，`N-0048` 的 14/20 会被误判通过。
2. **折级被当成硬门槛**：SPEC 明确标注折级为 `descriptive_only`，而实现把它并入拒绝理由。已改为 seed 级准入 + 折级随附报告（`decision.fold_criteria`），并保留 `enforce_fold_criteria=True` 供需要时收紧。
3. 另修一处会让结论完全反向的实现错误：复现阶段最初把**未混合的候选**直接与基座比较，得到 `−0.11 ~ −0.14` 分（候选单独精度差 6–7% 的必然结果），而不是混合增益；已改为按协议选权混合。该错误在被发现前未进入任何文档结论。

以上三条已固化为 `tests/test_round2_v5.py` 的回归测试，并重跑了 Stage 1（回溯校准仍 4/4 拒绝，`N2` 十格折级 8/10 仍被误放行 → 仍只靠 `insufficient_split_seeds` 拒绝）。
