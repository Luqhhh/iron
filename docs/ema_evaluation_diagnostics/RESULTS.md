## V4.5 的否定证据核验

原 diagnostic-r1 的 **20 个无修正 MAE 全部精确对应使用 seed3407 预测**，差异 0，包括按 seed42 分折的十项。这证明保存输出中存在源码所示的 seed 覆盖问题，不能再把旧表称为两套各自 seed 的基准诊断。真实铁口为 1/2，而旧 `spout_no>0` 指示全为 1；其铁口信息被抹去。

按正确 seed 分离的完整 MAE：铁量 20.156420 / 20.214326，时长 4.920896 / 4.904669。新的零拟合描述按真实铁口保存；尚未重拟合 logistic 或 median corrector，故**不能继续引用旧 AUC/修正收益作为修复后结论**。没有原执行源码哈希，历史身份结论限定为冻结输入及无修正输出归因，不宣称全部历史执行身份已证明。

此外，跨折混合 OOF 的修正器训练残差来自曾训练于外层测试标签的基模型，即便修正器自身划分了训练/测试也不能建立完整外层隔离。未来修正器的基模型内层交叉拟合、epoch/权重选择和修正器拟合必须全部位于外层训练池。

预定义的输入条件区域显示全局统计不能直接排除条件信号。例如按外层训练输入定义的低/高风量区域，铁量残差中位数分别为 **-0.776 / +0.995**（seed42）、**-1.073 / +0.947**（seed3407）。压力区和时长区也已保存。它们是描述性条件差异，尚未证明可学习的净修正收益，也没有完成 V29 的条件收益检验；不得据此临时加组、改样本或宣布重开整个方向。
