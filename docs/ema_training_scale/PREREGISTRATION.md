# BASE / EMA / SAM 训练规模机制实验（2026-10-01）

用户在已完成零拟合诊断后要求“继续”，本阶段落实 `docs/ema_evaluation_diagnostics/PREREGISTRATION.md` 的训练规模方案。目标是固定评估样本时检验原训练方法的规模响应。当前平台参照为用户回传 Q75=96.3920；不从本地结果预测平台收益或分数。

固定 seed42/3407 的 fold0 为各自评估集，完整五折文件保持原身份。剩余池按精确数值特征重复组保持整体，组内铁口集合定义分层；每层排序后用 RNG961046 随机排列，25%/50%/75% 取该层组数的向上取整前缀，100% 用整个池。子集嵌套且所有方法共享 ID，保留原训练行顺序；实际行数和铁口比例全部报告。分组、子集及内层 epoch 选择禁止使用固定评估标签；子集选择也不使用训练标签。

仅时间目标。原 `ComponentRegressor`、网络、损失、学习率、EMA beta、SAM rho、training/inner seed42、patience25 和 max_epochs240 均不改。每个子集独立分组内层选择 epoch，再新初始化 refit 于完整子集。三个方法共享每个子集的内层划分。100% 六个旧单位按原 complete/manifest、fit/query ID、saved state、epoch trace、原数据及冷预测身份核验后复用，不重训。18 个新估计器各含 selector/refit 两次优化器运行，全部保存两个模型和预测；36 次新 optimizer 上限，不重试、不追加确认 seed。

主结果按每个固定评估集计算 EMA−BASE、SAM−BASE 的 MAE 减少、WMAPE 减少和 `50*WMAPE减少` 分数点，报告 100% 与每个较小规模的方法效果差（difference in differences）。同时报告 selected/stopped epoch、内层标准化 train/validation MAE 及 gap、总更新步数/梯度评估、refit训练/固定评估 raw MAE gap、上限命中及各铁口效果。fold0 是事先固定的两个诊断集，不能代替两个完整 seed，更不能作为四 seed 正式晋级。这里的100%最多是2203行，不能解释成全2754行对隐藏测试的直接实验。固定 EMA beta 的平均跨度按更新步数生效，样本量、每epoch更新数和原训练程序共同变化；不把效果归因为纯样本量。

工程准入使用相同科学源、锁定 Python3.12 和原 full-size BASE/EMA/SAM G0 资源证据；不重复原资源训练、没有额外 synthetic fit。新子集构造、配对/隔离和防篡改检查必须通过。当前 RAM、单 worker RSS（1536 MiB）及保存状态检查保持原门槛。单 worker、单数值线程，上一 PTaRL/EMA 发布任务的成功完成事件、终态审计和 service MainPID0 必须先核验；训练阶段按600秒观察或实际结束事件处理，不在其间额外读训练指标。无时间预算、无运行时上限、无自动重启。

先保存完全冻结的源码/配置/数据/子集/旧模型清单和通过的锁定测试收据，再执行旧模型冷核验、18单位训练、新进程独立状态/算术/隔离审计。任何失败保留目录和失败凭证；不覆盖、不删模型、不复用部分训练。每单位 start/complete/failed 事件追加写入并fsync；科学程序不接收固定评估目标，评分只在训练结束后进行。源文件和身份在每个单位入口及最终审计再次核验。
