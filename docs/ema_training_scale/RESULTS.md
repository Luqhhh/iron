# BASE / EMA / SAM 训练规模诊断结果（2026-10-01）

## 判读和下一步

扩大训练池使三个方法在两个固定评估集上的绝对MAE都单调降低；**方法相对BASE的优势没有同样的规律**。EMA四规模均值为+0.005163/+0.013010/+0.003058/−0.001851，100%−较小规模在seed42三次均为正、seed3407三次均为负。50%均值最高但两划分一负一正，不能据此选择半量训练。当前证据没有观察到“规模越大、EMA相对收益越大”的统一机制，不能用它解释已有隐藏测试增益；最多2203行的诊断也未直接检验2754行全量拟合。

SAM从25%到100%的相对损失在两个划分都收窄，但100%仍分别−0.027403/−0.038360；100%相对75%反而两次下降。不存在可复现的单调规模优势，这不追溯否定已测平台SAM时长+0.0031的反例。

25%六个selector均碰240上限，而50%/75%/100%均按patience结束；小子集的效应混有优化进度限制。原完整池selected111–139、stopped136–164，单纯提高完整池max_epochs不会改变这些已提前停止的结果。若继续强化已获平台收益的EMA，下一次应在评估前冻结少量有效平均跨度/selector−refit更新步数机制的配对控制；先区分EMA的更新步跨度与训练规模，再讨论训练程序改进。本轮没有运行这些新控制，不能据此承诺提分、放宽四seed门槛或选择新平台包。当前PTaRL交付包反馈仍是独立证据来源，不与本表组件收益相加。
