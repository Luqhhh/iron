# EMA组件的完整外层隔离残差学习

2026-10-03，96.45持续授权内的新开发阶段。参照为最新登记的Q75=96.3920（用户回传、未经独立核验）。原残差实验的混合OOF依赖不能证明家族无效；原同F模型全局/压差校正相对Q75下降约0.028。本批检验一个不同且可部署的问题：在保留完整T训练EMA的前提下，使用T内部交叉拟合的残差训练修正器，是否增加Q75融合收益。历史失败决定、平台队列与模型缓存不改。

只研究时长。开发split42/3407各五个完整外层fold。每外层训练池T内，按group-safe seed27001分五个内折；每个内折的EMA只在另四折F上选轮、训练和预处理，原EMA beta=.99、原TabM配方、MSE、训练seed42和F内inner seed42选轮/fresh refit均保持。内折0复用原压差校准阶段的已保存F模型，其他四折新拟合。合并T内完整OOF时不跨outer fold或split seed。准备进程按冻结分区保存T标签和无标签query，各开发/冷审计worker只收到自己的T和无标签query；全集标签只用于分区准备及预测全部完成后的评分，不将外层query标签传入拟合。

两个固定修正器RIDGE、GBM，输入21个原数值特征、训练池词表的铁口one-hot和**EMA基预测列**。训练目标是T中真实时长减去T内EMA OOF预测。RIDGE采用训练池内StandardScaler及alpha=10；GBM保持旧残差实验的300棵、lr=.03、15叶、min_child_samples40、subsample=.8/freq1、colsample=.6、L2=1、seed42，改为单线程。无gamma、超参或特征搜索：预先固定组件修正强度gamma=.25。最终时长为`Q75+.75*.25*head(X,EMA_T)`，其中EMA_T是原来在完整T训练的同一保存预测器；铁量仍为Q75。未校正控制逐位等于Q75，没有缩小最终EMA训练池。

这是标准的训练池内cross-fit stacking：训练头时的EMA来自较小F，应用时来自完整T，训练规模迁移仍是限制，不能称完全消除。头不做额外交叉选权，避免混合内折OOF再用于标签选择；所有预处理、基础选轮和头拟合严格留在当前T内。该实验只检验EMA组件残差，不冒称已重训完整Q75的所有组成模型。旧开发标签已被反复使用，不称新独立样本。

冻结数量：40个新基础估计器、80次AdamW构造/基础预处理、80新状态；复用10个F和10个T估计器的40旧selector/refit状态；20次头拟合与20个头状态。工程测试单独只新增2个合成头拟合、0神经optimizer。每次科学构造前追加账本，并核验实际optimizer step与原生轨迹。0新确认seed、全2754行拟合、包、桌面写入、助手上传。没有时间预算或自动重试。

完整两split的两项固定预测都评分，增量单位为`50*(old_WMAPE-new_WMAPE)`。两seed均正者才有确认资格；最多选一个，按平均增量、1e-12并列RIDGE优先。现行candidate_tiers另行报告；正式晋级仍需至少四完整split、每seed正、seed层配对LCB95>0及随后冻结的确认门。未过门只否定本固定配方；不由任何结果推断平台上界或整个残差家族关闭。本阶段不自动安排平台名额。
