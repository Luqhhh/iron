# 未上传存货筛选（零拟合）预登记

日期：2026-10-05。规范：`configs/slot_inventory/SPEC.json`。实施：`scripts/slot_inventory.py`。规则来源：`configs/slot_screen/SPEC.json` 的 `slot_admission_rule`（冻结于同一天，状态 `prospective_unvalidated`）。参照 `DE3_IRON_EMA_MEAN3_Q100 = 96.3979`，目标 96.45。

## 问题

剩余额度只有在"现有存货里有够格候选"时才值得动用。本阶段把冻结的额度规则应用到**所有已记录、但从未产生平台分数的提交包**，判定是否有任何一个够格消耗一次额度。

## 规则（不自创，直接引用冻结定义）

一个包要成为额度候选，必须同时满足：

1. 通过既有本地门：**至少四个完整 split seed、各 seed 收益均正、seed 层配对 LCB95 > 0**；
2. 改动列相对父包列的回归斜率 `slope ≤ 0`（非扩张型）；
3. 合并扰动 `rho ≤ 0.01`；
4. 通过单列替换身份门，且其预测向量**不等于任何已评分包**（否则不构成新信息）。

## 方法

- 对每个存货包：读 ZIP → 与声明的已评分父包做单列替换身份校验 → 计算 `rho / bias_pct / slope / max_abs_pct / changed_fraction`；
- 与 24 个已评分包（23 份收据 + 其父包）逐向量比对，标记"重复于已测"；
- 输出每个包的通过/失败与拒绝原因。

若没有任何包同时满足 1–4，结论即为"现有存货中无额度候选"，本阶段不产生包、不写桌面、不上传。

## 预算

零拟合、零标签读取、零新包、零桌面写入、零上传；单进程单数值线程；无时间预算、无自动重试。

## 边界

几何规则是未验证的前瞻假设，通过它只是"不在已知危险类里"，不是收益证据；本阶段不预报平台分数、不改历史决定、不关闭模型家族。
