## G0 工程与预算

占位 152f2ba；本地实现 a2a3ab9d7c1e936250c526e99dd4cbde251b87ff。两臂同网络（2×64 ReLU 编码器、64 ReLU 隐藏头、单铁量输出），随机初始化，无预训练/外部数据/权重。完整 240 轮铁量 MAE 选轮、首次严格最优、fresh refit；候选训练 L1，控制 MSE。唯一端点 0.8×参照＋0.2×模型，没有权重扫描。详见 [SPEC](../../configs/iron_mae_compact_v1/SPEC.json) 与 [策略](STRATEGY.md)。

生产合成 G0 4 states / 4 optimizers；开发两个 seed 各五折两臂共 20 外层 arm models、40 selector/refit states / 40 optimizers，均新拟合。确认 0；没有复用旧控制、新增参照拟合、全量拟合、封包或上传。没有失败重试、改冻结规格或覆盖旧证据。

G0 冷审计 4 states 最大差异 0.00001010221752（原始单位），峰值 RSS 483.97265625 MiB。开发独立新进程冷审计 40 states 最大差异 0.00008433160303，峰值 RSS 483.453125 MiB；Torch/NumPy、行序、逐行与分块预测均符合冻结 0.0005 容差。全部单 worker/数值和 Torch 单线程，1024 MiB 门槛，无时间预算。

完整测试：神经 Python 3.12.3 为 1380 passed / 23 warnings；锁定 Python 3.12.13 为 1002 passed / 55 skipped / 3 warnings。最终另作零拟合独立重算：核验全部冻结源、控制器、环境、数据/参照文件、每个 state 的训练/查询身份、每个 seed 2754 行 OOF、端点文件、追加式预算计数及决策；与原审计一致，未改写原审计/决定。私有模型、预测、标签、账本及收据留 local/。
