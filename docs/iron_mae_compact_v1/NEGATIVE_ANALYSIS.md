已证实：候选及控制都显著弱于参照；候选具有较强的同向错误，固定融合没有获得互补收益。每个 seed 的两个铁口增量都为负，不是只有一个铁口造成总分下降。SCARF 预测平均偏差约 −2.26 / −3.40；VIME 约 +5.13 / −5.30，后者偏差方向随切分改变。没有证据支持简单全局偏置修正。

两轮完整 240 轮 selector 的最优轮数集中在早期：监督控制 15～29，SCARF 14～23，VIME 10～28。增加训练轮数没有直接依据；早期最优并不单独证明过拟合。两轮工程正确性证据与质量结论分开，负收益不宜归咎于推理打包错误。

推测而非已证实原因：约 2754 行数据对应五层 256 宽隐层网络可能容量过大；两目标联合 MSE 与铁量的绝对误差计分及选轮存在不一致；特征恢复/对比预训练未必保留对铁量有用的细微信号。现有结果无法分别识别容量与多任务效应，也不能否定整个自监督家族。

下一轮撤去预训练、减少容量、采用铁量单目标，在相同小网络中配对 L1 与 MSE。它直接测试损失对齐；网络容量和多任务改变相对旧网络仅作描述，不能宣称分别识别其因果贡献。新参数与选择门槛在看新 OOF 前冻结。保留平台与本地排序不一致的可能性；不把这两轮负结果预测成平台分数。
