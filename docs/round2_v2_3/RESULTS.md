## 机制诊断与限制

- **N1 尺度对照**：归一化独立 RMSE 与旧 C2 基本一致。N1 铁量 3.992080%，旧 C2 3.991918%；N1 时长 4.075341%，旧 C2 时长约 4.075389%。时长的正式参照已是完整 B3，因此 N1 仍未入围。
- **H1 稳健损失**：相比 N1，两组平均 WMAPE 铁量退化约 0.155193 个百分点，时长退化约 0.113844 个百分点。铁量两个切分中的最大绝对误差从 C2 的 144.397339 降至 136.138987，但总体绝对误差上升，不能据此认定模型改善或大残差标签错误。
- 按当前参照 OOF 绝对残差的五分位分组，H1 铁量最高误差组的平均绝对误差总和由 26981.868 降至 26916.033；最低误差组却由 1703.191 升至 3633.591。H1 铁量仅约 45.46% 样本误差低于参照，时长约 46.02%（均为两组比例平均）。保留失败结果，不继续扫描 delta。
- **J1 联合学习**：铁量有收益，时长退化；允许只选其铁量输出。固定的 C2/J1 等权融合 AJ 进一步将铁量平均 WMAPE 降至 3.928656%，比 I2 低 0.015571 个百分点。推理只使用白名单特征，不接收真实目标。

所有训练模型保存实际解析参数。观察到 N1/H1 使用 MVS bootstrap，J1 使用 Bayesian；N1/J1 的 boost_from_average 为 true，H1 为 false。三者叶值估计均为 Newton、1 次迭代。这是固定训练方案比较，不能将所有差异单独归因于损失或联合学习。

诊断 CSV `diagnostics/error_contributions.csv` 保存每组切分、每目标、每路线的整体和参照残差五分位：样本数、绝对误差总和、MAE、原单位最大绝对误差、误差贡献占比、WMAPE、优于参照的样本比例。分组只用于解释，不进入训练权重或推理路由。
