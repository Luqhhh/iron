# PTaRL代码路线：周期TabM原型辅助正则准备

目标仍为平台96.4 / 96.45 / 96.5；最高记录是用户回传V32_TIME_A60V7_50=96.3727，
未独立核验。RFM已在326ea4f负面结束，当前按既定顺序准备PTaRL。
没有重跑RFM、EMA、SAM、增强或DCN；保留旧门槛和全部负面证据。

## 先解决来源差异

[原论文](https://arxiv.org/html/2407.05364v1)的式5用原型投影表示进入预测头。
但[作者models.py](https://github.com/HangtingYe/PTaRL/blob/0c30b47d80e642c537feadf6e1542f0c5fc7bbc9/models.py)
的forward仍将原始潜表示送入预测头；坐标只进入辅助训练项。
[同版本训练代码](https://github.com/HangtingYe/PTaRL/blob/0c30b47d80e642c537feadf6e1542f0c5fc7bbc9/train_final_version.py)
还有三点具体定义：回归分箱使用log2；坐标约束使用全局分母、正对数均值并保留对角；
原型正交损失的L1偏离项系数为0.5，而非论文式7的1。

本设计明确选作者代码的辅助路线，避免将两种输出架构混在一起。
它是周期TabM的原创适配，不声称复现作者MLP/分类基准，也不声称等价于论文投影头。
只固定一套损失，不做paper/code两版竞赛或权重扫描。

## 已实现的数学和分区模型

当前实现：[损失核心](../../src/bf_tap_r2/ptarl_terms.py)、
[分区模型](../../src/bf_tap_r2/ptarl_model.py)、
[配对单元执行/审计](../../src/bf_tap_r2/ptarl_execution.py)、
[独立NumPy推理](../../src/bf_tap_r2/ptarl_verify.py)、[固定SPEC](../../configs/ptarl_space_calibration/SPEC.yaml)。
任务头保留强周期TabM的原始输出，按成员独立MSE训练、预测时取成员均值。
辅助几何使用同一次forward得到的成员潜表示均值；CONTROL与PTARL_AUX共享
全部结构、初始化、批次顺序和坐标dropout调用，只有辅助损失是否参与更新不同。
这是匹配float64对照，不冒充原生V7 float32精确重放。

原型成本采用单原子分布的精确可行运输计划：计划只能等于坐标概率。
没有Sinkhorn近似、POT依赖或额外求解参数。坐标分箱先从完整当前训练小批次计算，
再用独立有种子的半批抽样取配对；常数标签批显式同箱，单行尾批取一行。
零原型导致工程停止，避免破坏正交损失单位对角的前提。

在内层训练分区先训练BASE teacher，校准MAE选择epoch，只在它实际拟合的输入上
提取潜表示并拟合KMeans。外层teacher重新初始化，在完整外层训练按选中epoch训练，
重新估计变换、目标尺度和原型；不沿用内层中心。第二阶段也重新初始化任务网络，
不载入teacher权重。两个目标分别建teacher；另一目标不作为输入。

训练词表及21项数值标准化沿用NumericPreprocessor。样本ID只用于身份绑定。
KMeans输入的ID顺序及模型实际数值/类别张量均与teacher训练一致，不能用相同ID
冒充其他特征行。保存为私有weights-only Torch状态，冷加载要求外部SHA256锚点。
预测拒绝携带目标，未知铁口使用原生未知索引，反序/分块必须与同模型一致。

## 正式阶段仍待准入

本准备阶段只运行人工测试，官方标签/拟合、全尺寸资源探针、包及上传预算均为0。
模型核心可调用不意味着正式训练已获资源准入。正式阶段还需完整runner、预算账本、
原生四划分引用绑定、独立完整阶段审计、一次性控制器及全尺寸成本探针。
目前单元账本、单元执行和单元独立审计已经实现；完整阶段runner与账本汇总仍待完成。
G0工程与G1收益分开报告，不以人工损失、单模型误差或低相关性替代当前包增量。

计划每个目标/seed/fold共享两次teacher训练，再分别做两臂selector/fresh refit，
共6次优化、2次KMeans。完整开发20个配对单元共120次优化、40次KMeans；
这些是未来预算草案，尚未分配或消耗。必须先将完整执行阶段前瞻冻结才可测资源或拟合。

候选端点固定`.8*current+.2*member`，另一目标保持current，使用同seed原生引用。
42/3407完整五折均为正、均值至少+.01、优于CONTROL且包分至少96.25，才进入
7777/12011确认。最终需四seed全正、seed级LCB95>0及四seed控制优势。
确认seed是同样本的不同划分，不是独立新样本。fold仅描述，不跨seed平均OOF。
每600秒定时观察；完成事件可触发审计。没有自动封包、桌面写入或上传。

## 配对单元的工程见证

一个target/seed/fold单元保存六个weights-only模型；两个teacher的KMeans各有
成员标签、inertia及最终重分配后的中心均值残差。独立NumPy实现逐层重建
周期嵌入、BatchEnsemble、成员输出与潜表示，不调用生产网络或预处理器。
零拟合审计检验最近中心成员、中心均值残差和inertia，保留容差停止残差；
这不是重放KMeans初始化路径或重新聚类。专项公式与梯度测试另行覆盖辅助损失。

单元审计从外部完成摘要恢复所有模型/预测锚点，同时核对恰好1个单元、6次优化、
2次KMeans事件的输入身份及结果。失败/未完成预算不归还，目录不重入。
保存状态的选轮MAE、全外层重新训练epoch、匹配初始化、冷加载/反序/分块均核查。
两目标人工数据烟测通过新进程审计，范围仅为小尺寸单元准备，不是正式阶段准入。
