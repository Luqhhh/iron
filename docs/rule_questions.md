以下四项限于初赛/baseline 的时间语义；不是当前复赛瞬时特征的待补时序字段，本文不改变冻结契约。

1. 小时过程表的 `clock` 是统计窗口左端还是右端？当前 baseline 按官方行时间戳即其可用时刻处理；若官方答疑说明为左端，需增加窗口完成延迟并重建缓存。

3. `tap_iron` 与 `tap_time_len` 是否存在晚于 `tap_end_time` 的报送延迟？当前按堵口完成时可用处理。
4. 公共源同键同刻发生修订或冲突时，应按什么版本字段/规则取值？
