# 预登记：选轮噪声与轨迹平均筛选（2026-10-02）

## 动机（基于当日证据）

- 现有协议每个外层折只做**两件事**：用内层单一切分（外层训练集的 20%）选出一个轮次，再在外层训练集上按该轮数 refit 一次。已记录的选中轮次在 10 个单位里从 110 到 203 不等，说明选轮本身噪声很大。
- 本项目已证实"沿训练轨迹做权重平均"是**唯一在平台兑现的大额收益**（EMA 时长方向 +0.0168）。但现有实现只在权重空间、且只在 EMA 家族做过；**多折内层选轮**与**预测空间的多检查点平均**都没有测过。
- 样本量学习曲线显示铁量已饱和、时长轻度数据受限；两者都指向"减少方差"而非"增加容量"是当前唯一有机制依据的方向。

## 假设

H1：内层选轮用全部 5 折（而不是单折）会降低轮次选择的方差，从而降低 OOF WMAPE。
H2：在选中轮次附近取多个检查点做**预测平均**（快照集成）比单点 refit 更稳，降低 OOF WMAPE。
H3：铁量与时长对损失的偏好不同（余弦+L1 只改善铁量），因此**逐头损失**（铁量 L1、时长 MSE）优于两头同损失。

## 冻结设计

- 数据/折/骨架：与 [日程筛选](../q75_schedule_screen/PREREGISTRATION.md) 完全一致（联合 TabM + PLR 0.01、V12 训练设置、冻结折向量、授权公开的 `复赛_train/`）。
- 阶段 1（筛选）：`split_seed=42`、folds 0/1，配置：

| id | 说明 |
| --- | --- |
| `CONTROL` | 现有协议（常数 LR、MSE、单折选轮、单点 refit）；必须与已记录预测逐位一致 |
| `INNER5` | 内层 5 折平均验证 MAE 选轮，其余同 CONTROL |
| `SNAP5` | CONTROL 选轮后，refit 至选中轮次 ±20/±10/0 五个检查点，预测取平均 |
| `HEADLOSS` | 铁量头用标准化 L1、时长头用 MSE；常数 LR |

  共 4 配置 × 2 折 = **8 次正式拟合**。
- 阶段 2（确认）：阶段 1 中两折同向且平均优于 `CONTROL` 的前 2 个配置，在 `split_seed∈{42,3407}` × 5 折重训（每个配置 10 次，最多 20 次）。
- 阶段 3：若某配置在两 seed 均改善，则用四 seed 评审 npz 做**增量融合**（只改该目标列，权重由其余 seed 选出）。
- 控制闸门：`CONTROL` 逐位一致（1e-9），否则本阶段作废。
- 预算上限：阶段 1 + 阶段 2 ≤ 28 次正式拟合；无全量拟合、无包、无桌面、无上传。
- **冻结后更正（2026-10-02，阶段 1 首次运行之后）**：首次 `SNAP5` 臂因 harness 未把 query 帧传入 `fit` 而未生效（结果与 CONTROL 逐位相同），证据保留在 `local/runs/q75-selection-screen-20261002/stage1-r1/HARNESS_FIX.json`；修复后在 `stage1-r2` 重跑 `CONTROL`/`SNAP5`/`COS_MAE_INNER5` 共 6 次拟合。因此预算上限更正为 **≤34 次**（8 + 6 + 阶段 2 最多 20）。修复只改 harness 的传参，不改已冻结的对照、判读或门槛。
- 资源：单数值线程、worker ≤ 6、峰值内存 1536 MiB/worker；不设时间预算。
- 判读：只把两 seed 同向改善者列为候选；单折或单 seed 改善不构成晋级。
