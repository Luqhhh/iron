## 发现一：同一改变向量、不同起点，"效果"差 0.0143

`LOC_DIAG_EMA_TIME = V32 + 0.5·(EMA_time − V7_time)` 与 `EMA_TIME_Q100 = LOC_DIAG + 0.5·(EMA_time − V7_time)` 的**改变向量完全相同**（322 行逐行最大差 2.84e−14）。它们的平台结果却是 **+0.0168 与 +0.0025**，相差 0.0143。

也就是说：改变本身不能决定结果，**起点的残差配置**才是主导。这一条只用我们自己的包与回传分数就成立，不依赖任何标签。

对照自然实验：`DE3_IRON_USER_REQUESTED` 与 `DE3_IRON_EMA_MEAN3_TIME` 的铁量改变向量完全相同（最大差 0.0），在两个不同起点上的平台结果 +0.0022 与 +0.0023，几乎一致。两个自然实验方向相反，说明"起点依赖"至少对时长列很强、对铁量列在本例中很弱，**不能把它推广成统一规则**。

## 判读与边界

1. **本阶段没有找到可用的平台预测器。** 五个统计量高度相关（都在度量"改动有多大"），未做多重比较校正；23 份回传共用同一批 322 行、多数共用同一 incumbent，不是独立样本。任何单个 p 值都只是描述。
2. **可以确立的只有一件否定性事实**：在这批回传覆盖的范围内，**扩张型改动 10/10 全部下降**，8 个正增量全部来自非扩张型改动。这支持"平台只奖励继续做方差缩减/继续平均的改动，注入新离散度的改动会下降"这一机制读法，但它与候选家族、时间批次混杂，且没有独立验证。
3. **筛选不充分**：13 个通过`slope ≤ 0 且 rho ≤ 0.01`的候选中仍有 5 个下降（最差 −0.0213）。通过筛选只是"不在已知的危险类里"，不是"会涨"。
4. **它也可能漏掉真正的突破**：如果某个新模型真的更好，它必然大幅改动预测，因而会被本筛选判为"危险"。本筛选只在"没有突破"的历史区间内标定，无法区分"大改动＝噪声"与"大改动＝真信号"。
5. **不预报平台分数**，不改历史门槛、晋级或失败结论，不关闭任何模型家族，不推断剩余额度。

## 对 4 次额度的直接含义

- 近阶段单次最大平台增益是 **+0.0168**；正增量组均值 **+0.0041**。把 4 次额度全部押中"正增量组平均"，终点也只有 **96.414**，离 96.45 差 0.036。
- 要补上 0.0521，需要**每一次额度都达到历史单次最大增益（+0.0168）并再多一点**，或一次拿到 3 倍于历史最大值的增益——23 份回传里没有出现过这类量级。
- 预期价值最高的用法是把额度留给"非扩张型、扰动极小、且通过既有四 seed 本地门"的候选，每次期望提升约 0～+0.003，终点约 **96.40–96.41**；这是收益最大化路线，不是 96.45 路线。
- 因此 96.45 在当前证据下**不可达的置信度很高**（仍未证明不可能）。唯一逻辑上可能的路径是出现一个精度或结构上真正不同的模型；这类候选必须带独立证据（例如真正隔离的外层样本），不能只凭本地增益。
