# 额度筛选复核（零拟合）预登记

日期：2026-10-05。规范：`configs/slot_screen/SPEC.json`。实施：`scripts/slot_screen.py`。参照：`DE3_IRON_EMA_MEAN3_Q100 = 96.3979`（用户回传，未独立核验）。目标 **96.45**。

## 问题

用户剩余 4 次平台提交额度，路线为"先开发新机制＋隔离外层筛选，证据合格才用额度"。在开发之前必须先回答：**本地与平台之间到底有没有可用的筛选量。** 本项目已有 23 份"单列替换、父包已评分"的候选回传，每份都带 322 行预测向量与已登记的平台增减。这些数据可以零拟合地回答该问题。

## 范围与预算

- 只读：仓库内已记录的提交包（我们自己的产物）、`EVIDENCE_STATUS.json` 中已登记的平台分数与本地增益。
- 不读：任何训练标签、测试标签、平台凭证；不训练、不预测、不封包、不写桌面、不上传。
- 预算：新目标估计器 0、optimizer 0、确认 seed 0、全量拟合 0、包 0、桌面写入 0、助手上传 0。
- 单进程、单数值线程；无时间预算，不自动重试。

## 身份门（先于任何统计）

每份候选必须通过与已评分父包的**单列替换**身份检查，否则整对剔除并在报告中记录原因：

1. ZIP 只含 `result.csv`，322 行、322 唯一 ID、官方模板顺序、有限非负；
2. 恰好一个目标列改变；
3. 未改变列的 CSV 字段与父包**逐字符串相同**；
4. 父包 ZIP SHA256 已登记。

这条门把"改变向量"的定义钉死：平台增减只可能来自那一列。

## 统计量（每对，冻结定义）

在改变的那一列上，`Δ = 候选 − 父包`（322 维）：

| 名称 | 定义 |
| --- | --- |
| `rho` | RMS(Δ) / mean\|父包列\| |
| `bias_pct` | 100 × mean(Δ) / mean\|父包列\| |
| `slope` | Δ 对父包列的 OLS 斜率 |
| `max_abs_pct` | 100 × max\|Δ\| / mean\|父包列\| |
| `changed_fraction` | 预测字符串发生改变的行比例 |

平台侧因变量：已登记平台分数差；本地侧自变量：已登记的本地增益（有出处者，缺失记 null）。

## 先验假设（登记后不得追改）

- **H1**：平台增减与本地增益的关系不显著，或为负。
- **H2**：平台增减与扰动幅度 `rho` 负相关（改动越大越危险）。
- **H3**：平台增减与 `slope` 负相关（扩张型改动比压缩型更差）。
- **H4**：存在"同一改变向量、不同起点、不同平台结果"的自然实验，说明平台响应由起点残差配置主导。

H1–H4 都是**描述性**检验：23 份回传非独立（共用父包、共用 322 行），且五个统计量未做多重比较校正。任何单个 p 值都不构成确证，也不能据此预报平台分数。

## 产出

1. 逐对证据表与 `report.json`；
2. 自然实验块（相同 Δ 的对）；
3. 冻结的**额度准入规则**（`slot_admission_rule`），状态明确标为 `prospective_unvalidated`：其阈值来自这批回传本身，只能用于下一次候选的前瞻登记，不能回写历史决定；
4. 实证额度价值估计：平台正、负两组实际增量的分布。

- 不关闭任何模型家族，不改历史门槛、晋级或失败结论；
- 不因本次分析推断剩余额度或安排测试。
