# 预登记：TabM 超参筛选（2026-10-02）

## 动机

本项目的 V7/V12/V36/EMA 等全部配方都使用同一组**默认**超参（width 256、2 blocks、k=16、dropout 0.1、lr 1e-3、wd 1e-4、batch 256、240 轮、PLR frequency 0.01、n_frequencies 16、embedding_dim 16）。历史上只粗测过容量三档（small/medium/large）与两个更大容量探针（V25，均更差），**没有系统扫过学习率、dropout、权重衰减、批大小、PLR 频率与嵌入维度**。

当日筛选已显示单点超参效应与日程效应同量级：`COS_DROP0`（dropout 0）铁量两折同向 −0.000401、`COS_LR3`（lr 3e-3）铁量两折同向 −0.000390。若这些方向可叠加，铁量列存在 +0.001 WMAPE 量级（约 +0.05 分）的空间。

## 假设

H1：默认超参不是该数据的最优点；在某些方向（学习率、dropout、权重衰减、PLR 频率/嵌入维度、批大小、k/blocks/width）上存在两折同向的净改善，且可与"余弦 + 标准化 L1"叠加。

## 冻结设计

- 数据/折/骨架：与日程筛选一致；只有超参（与 PLR 频率）变化。
- 阶段 1（筛选）：`split_seed=42`，folds 0/1；配置表（全部为**单因素**改动，除最后一行）：

| id | 改动（相对 V12 默认） |
| --- | --- |
| `CONTROL` | 无（逐位一致闸门） |
| `DROP0` | dropout 0 |
| `LR3` | lr 3e-3 |
| `WD1E3` | weight_decay 1e-3 |
| `BATCH128` | batch_size 128 |
| `FREQ001` | PLR frequency_init_scale 0.001 |
| `FREQ01` | PLR frequency_init_scale 0.1 |
| `NFREQ32` | n_frequencies 32 |
| `EMB32` | embedding_dim 32 |
| `K8` | tabm_k 8 |
| `K32` | tabm_k 32 |
| `BLOCKS3` | blocks 3 |
| `WIDTH384` | width 384 |
| `COS_L1_LR3` | 余弦 + L1 + lr 3e-3 |
| `COS_L1_DROP0` | 余弦 + L1 + dropout 0 |
| `COS_L1_LR3_DROP0` | 余弦 + L1 + lr 3e-3 + dropout 0 |

  共 16 配置 × 2 折 = **32 次正式拟合**。
- 阶段 2（确认）：阶段 1 中**两折同向**且平均优于 `CONTROL` 的前 2 个配置（按合成分排序），在 `split_seed∈{42,3407}` × 5 折重训 = 最多 **20 次**。
- 阶段 3：仅对阶段 2 中两个 seed 均改善者，在四 seed 评审 npz 上做增量融合评估（零新拟合）。
- 控制闸门：`CONTROL` 逐位一致（1e-9），否则作废。
- 预算上限：32 + 20 = **52 次正式拟合**；无全量拟合、无包、无桌面、无上传。
- 资源：单数值线程、worker ≤ 6、峰值内存 1536 MiB/worker；不设时间预算。
- 判读：任何单折/单 seed 改善不构成晋级；本地增益不得写成平台预测。

## 边界

不改 incumbent、不覆盖既有目录、不改历史门槛；不重开已关闭的容量档探针（V25 的两个更大容量点保持关闭，本表只测单因素轻度改动与叠加）。

## 冻结后扩展（2026-10-02，阶段 1 与 K32 阶段 2 之后）

阶段 1 中只有 `K32`（`tabm_k` 16→32，其余默认）两折同向改善两个目标（铁量 −0.000436、时长 −0.000669）；阶段 2（2 seed × 5 折）显示 K32 相对**单配方对照**时长两 seed 均改善（+0.000666/+0.000588）、铁量混合（+0.000327/−0.000005），相对 **incumbent 列**铁量仍差、时长持平。

因此追加**阶段 1b**：在 K32 之上叠加已显示正向的协议改动，检验是否有复利：

| id | 改动 |
| --- | --- |
| `K32` | k=32（阶段 2 已确认，作为 1b 的对照） |
| `K32_COS_MAE` | k=32 + 余弦 + 标准化 L1 |
| `K32_FREQ001` | k=32 + PLR frequency_init_scale 0.001（阶段 1 中时长两折改善） |
| `K32_COS_MAE_FREQ001` | 三者叠加 |

- 单位同阶段 1（`split_seed=42` fold 0/1），4 配置 × 2 折 = **8 次正式拟合**；总预算 42 + 8 = 50 ≤ 52，不新增确认预算。
- 判据同阶段 1：两折同向且平均优于 `K32` 对照者进入四 seed 扩展（另行冻结）；否则关闭该组合。

## 冻结后扩展 2（2026-10-02，阶段 1b 之后）

阶段 1b 显示在 K32 之上叠加余弦+L1 或 PLR 频率**均无复利**（全部变差或持平），因此 K32 是当前最佳单配置。唯一尚未测的方向是**继续增加内部集成宽度**（k=32 是阶段 1 中最有效的单因素，机制上是"更多内部成员 → 方差下降"，对数据受限的时长最有效）。

追加**阶段 1c**：`K32`（对照）、`K48`、`K64`、`K96`，单位同阶段 1，4 配置 × 2 折 = **8 次正式拟合**；预算上限由 52 更正为 **58**。判据同上：两折同向且平均优于 K32 者进入四 seed 扩展（另行冻结）。
