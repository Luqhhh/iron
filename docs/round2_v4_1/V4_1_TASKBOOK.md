## 2. 源码确认的三个覆盖缺口

### 2.1 直接替换、50/50 混合，不等于测试所有正向增量

`src/bf_tap_r2/v4_run.py::_metrics_for_unit` 仅评价 candidate 和 0.5*A+0.5*candidate。没有训练部分内的自适应混合系数，也没有证明从 A 出发的候选方向无法改善。

这不否定 V4 已有负分数，只限定负结论的范围：它排除了这批实现的整列替换和固定 50/50 组合，不能据此排除低权重补充、强基线残差专家等尚未正确验证的流程。

### 2.2 V4 全部新模型未接收 spout_no

`_fit_unit` 传入 `train[list(FEATURES)]`；`data.py::FEATURES` 仅有21个数值列。项目数据契约另有 `categorical_features=[spout_no]`。因此，新模型与完整 A 在可用输入上并不一致。

这是一个真实覆盖差异，不是已证明的退化原因。禁止宣称“补上铁口必提分”；用少数成对对照检查。

### 2.3 三元 EBM 没有保留原二元交互集合

`v4_smooth_models.py::fit_ebm_with_explicit_triple` 设置 `interactions=[term]`；与之比较的 S5 设置 `interactions=60`。两者不是“相同 pair 模型 / 相同 pair 模型+triple”，而是不同的 interaction 集合。

此外，V4 EBM 代理固定原单位训练、max_rounds=1000、max_bins=64；强历史 EBM 配方还包含其自己的目标坐标、训练预算、类别输入与 group-safe bags。不能把代理分数直接解释为强配方上该结构机制的上限。

P3 使用 LinearControlRegressor 作基模型；真正的 B_star 残差 P4 被 blocked。P3 的失败不是“完整 A/B_star 残差已经测过”的证据。

## 3. 阶段 D0：先复用已有 OOF，零模型训练诊断

直接运行随附 `diagnose_v4_oof.py`。它读取 coarse-r2 现有 76 份可评分事件，不新训练模型、不生成新折、不读取测试、不生成提交文件、不写远端。

设 r=y-A，d=candidate-A，固定方向损失为：

L(alpha)=Σ|r_i-alpha*d_i|，0≤alpha≤1。

对 d_i≠0，令 q_i=r_i/d_i，则最优系数是 q_i 以 |d_i| 为权重的加权中位数，并截到[0,1]。这消除了密集权重网格。方向导数必须正确处理 r_i=0：

L'_+(0)=-Σ_{r_i≠0}sign(r_i)*d_i + Σ_{r_i=0}|d_i|。

在这一固定数据集、固定方向、凸损失下，L'_+(0)≥0 表示任何正 alpha 都不会使该路径优于 alpha=0；负导数表示存在小正步改善。它不证明该方向能泛化。

工具报告原单模型 delta、原 50/50 delta、方向导数、同标签最优 alpha、同标签最大 delta。全部 oracle 列显式标记 SAME_LABELS / NOT_VALIDATION。

**禁止把同一 OOF 上选权再评分得到的结果用于晋级、封包或平台预测。** 两个 seed 来自同一批标签，交叉用 seed42选权/3407评分也不能冒充严格独立验证。

D0 决策：两个 seed 的 oracle 增益均为正、平均≥0.02 的旧方向，最多选择6个进入真正嵌套复测。不达标的方向不扩参数。不把0.001的微小诊断收益作为平台候选。若无方向入围，D0正常结束；它不阻塞下面对未覆盖机制的有限修正。

工具输出仅是原 OOF 上单候选凸组合路径的乐观包络，不是整个模型家族、条件门控或未来性能的上界。

## 4. 阶段 R0：恢复可调用的完整强基线

实现/恢复一个版本化工厂：`fit_baseline(training_frame, seed, protocol) -> predictor`，使其能够只在给定训练样本集合内完成完整训练。

优先 B_star；若缺完整来源，先用完整 A 流程，明确输出 A-relative，不给 A_dev 人工增加0.0012。需要区分：

- 平台原包：用于保存最佳结果与列身份，不是可训练基线工厂。
- 历史 A_dev OOF：用于D0描述性诊断，不是所有外层训练子集的残差缓存。
- 完整 A/B_star 算法：能在任意指定训练集合内生成成员、内层OOF、选权、重训，才能用于嵌套增量验证。

缓存必须绑定完整训练ID集合、group集合、目标、原始特征与类别词表、模型/交互配方、内层协议、环境和源码哈希。相同缓存可在多个修正器之间共享；不同训练集合不能复用。原件驱动在平行分支已有恢复记录，优先查证实际handoff文件，不从缺失文件名猜配方。

能力恢复不得占据所有优化预算：恢复A后即可进行修正线；B_star无法恢复则只阻塞B_star级的最终晋级声明。

| 单元 | 内容 | 回答的问题 |
|---|---|---|
| C0 | 原V4 S5，21数值列 | 已执行对照；不凭空给它换参数 |
| C1 | C0完全相同设置，仅加入正确编码的spout_no | 输入遗漏是否造成实质差异 |

spout_no 在EBM中明确为类别；在样条或距离模型中用训练部分拟合的词表/独热编码。不要改变已冻结数值特征的索引；采用名称映射生成tuple并保存映射。

本阶段最多10个单元，不因为C1/C4略差便续开bins、树深度、学习率网格。两个目标分别择优；铁量有效不要求时长一起改变。

## 6. 阶段 E：模型只学习强基线没解释的部分

本阶段不是把V4弱模型再和A等权，而是定义：

prediction=B(x)+alpha*h(x)。

B是完整A/B_star，h只拟合内部交叉拟合残差 y-B_OOF。四种修正器、两个目标，共8个单元（包含最简单控制），不搜索大网格。

| 修正器 | 结构 | 核心区别 |
|---|---|---|
| E0 | 训练内部残差中位数常数修正 | 区分全局偏差和真正条件结构；必有零修正回退 |
| E1 | 低自由度一元样条的中位数/LAD残差模型 | 改变为原单位绝对误差对应的位置估计，不从头重学全部目标 |
| E2 | 线性叶残差模型 | 让F6表达局部误差，而非承担完整目标预测；使用锁定实现支持的训练损失 |
| E3 | 预测状态空间中的局部残差加权中位数 | 以强模型预测和成员分歧定义邻域，而非在原始21维上从弱森林重新分区 |

E1采用训练部分内拟合的低自由度样条、类别独热与固定正则，不枚举loss与knots组合。若选用 sklearn QuantileRegressor，需要在锁定环境核实其接口与收敛状态，q固定0.5。

E2使用经能力检查的linear_tree实现；不指定不支持的regression_l1。修正的监督值可正可负，禁止沿用正目标的log1p、下界截断或非负预测包装器。

E3初始状态向量固定为：B_iron预测、B_time预测、两侧各一个预声明的“CB成员均值−EBM成员均值”分歧。最多4维，缺某一来源则删除该维并记录，不用真目标填充。银行坐标与残差来自内部OOF；查询坐标来自在允许训练部分拟合的同配方模型。缩放/距离尺度只用训练银行；邻居数固定min(128,银行样本数)，对不足支持收缩到零。不扫描k、温度或状态向量组合。需要记录OOF银行与完整训练查询的训练规模差异，并由外层验证检验其净效果。

所有h默认仅增加一层，禁止递归“基线+残差+残差”。E0只能作为控制或组合材料，不能据一个微小全局bias收益展开平台试探。

## 7. 嵌套实现：不能把全局OOF切片后当作干净训练特征

外层训练T、评价V。要选择alpha或其他修正器内部超参数，完整复合流程也必须交叉拟合：

```text
for meta-fold (U, W) inside T:
    # U、W按group隔离
    construct base OOF strictly inside U
    fit h_U on (X_U, y_U - base_OOF_U)
    fit complete B_U using U only
    predict b_W = B_U(X_W), d_W = h_U(X_W)

fit alpha on concatenated (y_W, b_W, d_W), using T only
rebuild base OOF strictly inside full T
fit h_T on its residuals; fit complete B_T on T
predict V with B_T(X_V) + alpha*h_T(X_V)
score V only after all learning/selection is finished
```

基线自身若有成员选权，也属于B_U/B_T内部过程。只在T上生成一次base OOF后再随意切成U/W训练h，会让W标签经部分base模型进入h的训练输入；不得把这种结果标为严格外层验证。

对D0旧独立模型方向的复测，alpha也只在外层训练部分内部的OOF上求解。D0导出的oracle_alpha绝不直接用于V或测试。

默认alpha区间固定[0,1]、含零回退，使用随附精确L1求解器，不扫cap。多个修正器之间最终选模型也只允许在训练内部。真实fit成本由模型调用计数，不用“18单元”掩盖内部重训；不同E线共享同一训练集合的base OOF和B模型缓存。
