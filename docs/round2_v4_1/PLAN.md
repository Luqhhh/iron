## 目标与边界

当前最高用户回传为 `V36_USER_REQUESTED_OUTER_FAILED = 96.2734`，距严格大于
96.3 还差 0.0266。V4 已表明低容量独立机制不能接近强基座；本轮不再重复
直接单模型粗筛，而是测试“强锚点预测之后是否还有可交叉拟合的系统残差”。

本机器没有远端 V3.4/V3.6 的私有 OOF 和模型缓存，因此不伪造 `V34_A`或
`V36` 重放。锚点只使用公开配置可精确重建的 V34 EBM 专家：

- 铁量：`0016/0020`，按 V34_A 中两个 EBM 专家的相对权重归一化；

所有结果只能称为相对于该公开可重建锚点的机制证据，不是 V34_A/V36 得分。

- 外层开发切分：seeds 42/3407，粗筛只用 folds 0/1。
- 在每个外层训练部分内，使用 3 折重复组隔离的交叉拟合锚点预测构造
  `y - anchor_oof`。残差模型不得看到同行拟合值或外层验证标签。

  4 个/目标。所有容量、损失、修正系数和裁剪规则已在 YAML 中冻结。
