## 为什么选这个方向

最新远端基点为 `codex/strong-component-regularization` 的 `de593e712f13081e173d7d66b4e9a0f012f9e2a5`。登记的平台最佳为 EMA_TIME_Q75/Q100 **96.3920**，用户回传、非独立平台凭证；Q75 因外推较小作同分代表。PTARL_TIME_Q20 回传 96.378，未超越当前最佳；Q75 压差校准未获确认资格。队友已经预登记 EMA 平均跨度 SHORT/LONG，本方向不重复该实验。具体证据：

- [当前 EMA 交付与反馈](../ema_time_followup/DELIVERY.md)。
- [压力校准结果](../q75_error_relocation/CALIBRATION_RESULTS.md)。
- [队友 EMA 平均跨度协议](../ema_average_span/PREREGISTRATION.md)。
- [PTaRL/EMA 探索交付](../ptarl_ema_exploration_release/DELIVERY.md)。

ModernNCA 是队友已完成部分工程准备、但尚无正式赛题质量结果的路线，**不是本次新发现的模型**。此次新的尝试身份是铁量单目标、绑定当前 Q75 的原生铁量参照，并补充完整尺寸资源路径。学习样本间的距离，再直接以非负归一化权重聚合训练标签，可提供不同于原有树模型/MLP 的预测几何，值得完整覆盖的配对验证。

此前 TabR 检索预测头和全局 RFM 核路线的负面结果降低先验信心；它们未测量本配方的“可学习距离＋直接凸标签聚合”，不能替代此次对照。也不能据此声称 ModernNCA 一定有效。

AMF 首个合成 G0 可学性与独立冷推理通过，但 RSS 超过冻结 1 GiB 门槛而停止，正式开发/确认均为 0。该结果是资源准入失败，G1 未测；不重试旧预算，不把它写成质量失败。AMF 查询分批推理的资源修订可留作备选，需要新的身份与预检，优先级在本方向之后。

## 拟保留的模型配方与对照

只研究 `tap_iron`，保持时长列原样。两臂为 LEARNED_ENCODER 与同初始参数的 FIXED_ENCODER；固定臂为机制对照，优化器调用 0，不可单独晋级。距离为未平方欧氏距离，softmax 负距离直接加权训练响应，无额外残差头。

以下拟复用队友固定作者配置配方，不做参数池搜索。`sample_rate=0.5` 来自该配置，不是作者构造器默认值：

| 项目 | 拟定值 |
|---|---|
| 编码 | PLR-lite；128 维；post-encoder blocks=0 |
| PLR | frequencies=77，embedding=34，frequency_scale=0.04431360576139521 |
| 邻域 | temperature=1.0；训练 candidate sample_rate=0.5 |
| 训练 | AdamW，lr=0.01，weight_decay=0.0002，训练 seed=42 |
| 批次/选轮 | batch_size=256；max_epochs=240；patience=25；min_delta=0 |
| 数值 | 保留作者 float32 初始化后转换 float64 |
| 目标/损失 | 训练分区均值与总体标准差归一化；normalized MSE |
| 校准 | 内层校准 MAE 首次严格最优；外层训练分区全新预处理/初始化重拟合 |

数值变换、spout 词表、目标标准化和邻居标签库都只拟合相应训练分区；校准/外层查询标签不得进入邻居库。重复组按原生 21 特征定义，训练候选排除当前批次所有同组样本，批内屏蔽自身及同组响应。保留已准备的空候选拒绝规则，不增加临时回退。

## 参照与可识别的收益

当前 Q75 铁量字段与 V32 原生铁量相同（交付记录及平台反馈身份核验），本机已有对应完整四 seed 参照。此次零拟合核验确认原生铁量 OOF 列逐 seed 与原 DE3 清单的 `parent_digests` 一致，四 seed 均 2754 行，原五折身份保持；新参照拟合 0。模型、预测数组、原配置和核验明细留私有 `local/`。

Q75 时长四 seed 缓存尚未收到。因此：可以识别相对当前铁量的净分增量，**不能计算 Q75 完整本地包分**，也不能拿旧 V32 时长冒充 Q75。按等权两列 WMAPE，保持时长不变时：

`delta_score = 50 * (WMAPE(current_iron) - WMAPE(endpoint_iron))`。

拟固定 isolated A20：`endpoint_iron = 0.8*current_iron + 0.2*member_iron`；不扫权重、不跨 split seed 平均 OOF。DE3 铁量作为已有缓存的辅助比较，不能把未平台实测的 DE3＋Q75 替补包注册为当前最佳。历史 B0 增量单独报告，主要决策相对冻结时的最新目标参照。
