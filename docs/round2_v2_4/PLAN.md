# V2.4：平滑主项与树残差

目标是在现有两个待测包之外，继续寻找新的单目标平台验证候选。先冻结这一轮，不根据结果调整参数、权重或门槛；不足三个时须根据结果提出另一个明确假设，不能改标签凑数。

三条基础路线：BAY（归一化独立 RMSE，Bayesian bootstrap、temperature=1）、R30（原独立 RMSE 的 l2_leaf_reg=30）、QRC（训练折内标准化二阶多项式 Ridge alpha=10，再由 depth4、1500 树 RMSE 补充其训练残差）。后者是一个联合训练流程，不是用外层验证残差训练校正器。尺度、标准化、类别编码都仅在训练折拟合，推理只接收特征。

每条路线另固定与当前目标参照等权融合，铁量额外冻结 DJ=.5 C2+.25 D4+.25 J1，复用现有同折预测。C2 铁量和完整 B3 时长仍是分类参照；另报告对 I2/AJ 铁量、T1 时长的差值。T1 只作历史比较，不恢复其待测地位。

候选池、平局顺序见 experiment.yaml；直接使用 candidate-tiers-v1，每目标一个正式推荐、跨目标至多一个探索推荐，不增加组合包。旧 42/3407 五折是已多次使用的开发验证，非独立确认；推荐者保留 2000 次样本组成敏感性报告，不当作晋级门槛。

预算：60 次 CV 包装器训练，内部 60 CatBoost +20 Ridge，合计80个回归器拟合；后续只为推荐所需路线全量训练，每目标/路线最多一次、包装器上限3。模型、逐样本预测、账本、报告和提交 ZIP 全部保留在 local/。现有 V22_I_ONLY、V23_AJ_I_ONLY 包与顺序不变；用户自行上传，不询问额度。
