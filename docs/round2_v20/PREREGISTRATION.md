## 1. 要检验的假设

**现有模型只从两个标签学。每行 21 个输入之间可能存在与目标有关的共同结构，这部分监督信息尚未被利用。**

训练时让同一编码器同时承担两项任务：

```
L = L_目标预测 + λ · L_遮蔽重建
```

- 完整输入 → 预测时长（损失形式与 V7 完全一致，不改 MAE/Huber/分位数）；
- 随机遮蔽少量数值输入 → 从其余输入重建被遮蔽项；
- 推理只用目标预测头，不改变交付路径。

**本实验的主要风险是"成功重建特征 ≠ 成功提分"。** 因此 §5 把"重建可学"与"目标改善"
设成两道独立的门，且门 1 明确**只看目标指标，不看重建损失的高低**。

| 外部数据 / 外部预训练权重 / 额外预训练阶段 | 全部禁止；从随机初始化同步训练 |

## 3. 对照设计（严格配对）

只做时长列。以 V7 的强网络 `tabm_plr001` 作为**匹配对照**。

| | 对照臂 C | 候选臂 A |
|---|---|---|
| 骨干 | `tabm_plr001`（backbone tabm, frequency 0.01） | **完全相同** |
| 目标 / 损失 | `tap_time_len`，MSE，逐子模型监督 | 同 |
| 初始化与训练随机种子 | V7 `random_seed: 42` | 同 |
| split seeds / folds | 42, 3407 / 完整五折 | 同 |
| 训练预算 | `max_epochs 240, patience 25, batch 256, lr 1e-3, wd 1e-4, k=16, width 256, blocks 2` | 同 |
| 预处理 | `inner_training_only_then_refit_outer_training` | 同 |
| 交付混合比 | V7 固定 0.5 槽位 | **同，不单独调** |
| 新增 | — | 遮蔽步骤 + 重建头 + `λ·L_recon` |

**臂 A 相对臂 C 只多一个东西：重建任务。** 架构、种子、预算、槽位全部冻结。

### 3.1 实现方式（不改冻结的 V7 代码）

新建 `src/bf_tap_r2/v20_masked_recon.py`，**不修改** `v7_periodic.py`（其 `code_sha256` 是冻结身份）。
重建头挂在 TabM 共享主干上，与输出头平级：

```
stem(x_num, x_cat) → ensemble_view → backbone → ┬→ output   → 目标预测 (B, K, 1)
                                                └→ decoder  → 重建      (B, K, 21)
```

`decoder = LinearEnsemble(width=256 → 21, k=16)`，即**逐子模型的重建头**，
与 TabM 已有的逐子模型输出头对称，保留"逐子模型监督"这一既有性质。

每个 batch 两次前向：完整输入算 `L_target`（形式与对照臂逐字相同），
遮蔽输入算 `L_recon`。只有遮蔽那次经过 decoder。

### 3.2 遮蔽与尺度处理

- 只遮蔽**数值特征**（21 列），类别列不动；
- 遮蔽率 `p = 0.15`，逐行独立 Bernoulli；
- 填充为**标准化后置零**（记明这是零填充去噪，不声称等价于缺失机制）；
- 重建目标为标准化后的原始数值；
- **重建损失按被遮蔽项取平均**，不按特征数求和，避免大尺度特征支配；
- 所有标准化尺度只在**当前训练部分**拟合，与 V7 既有契约一致。

### 3.3 唯一变量范围（首轮不扫）

`p = 0.15`、`λ = 0.2`，两者**先验固定、不搜索**。不扫遮蔽率、不扫 λ、不扫架构、
不加 raw skip、不加额外注意力、不扩宽加深。若门 0/门 1 通过，允许的**第二规格只有一组**
（见 §5 预算），不靠不断调参延续实验。

## 4. 计算成本（已实测，非假设）

单折 outer fit（551 行，单线程，`OPENBLAS/OMP/MKL/NUMEXPR=1`）：

| 骨干 | 单折 |
|---|---:|
| `tabm_plr001` | **108 s** |
| `mlp_plr001` | 3.5 s |

开发阶段 20 个 outer fit（2 臂 × 2 seed × 5 折）≈ **36 分钟**单线程，8 worker 下更短；
重建头与第二次前向会略增，按 1.5–2× 预留。**不使用满量拟合。**

## 5. 门（按顺序，每道不过即停）

**门 0a — 合成可学性（最便宜）**
在合成数据上（已知特征间存在线性关系）验证重建头能学到超过"逐特征常数预测"的关系。
不过 → 停止，机制在当前实现下不成立，不进真实数据。

**门 0b — 对照臂复现身份**
用**同一份新代码**、`λ = 0`、`p = 0` 跑对照臂，输出必须复现 V7 已缓存的
`local/runs/round2-v7-periodic-networks/development-r1/tap_time_len-tabm_plr001-s{seed}-f{fold}.npy`。
不复现 → **实现有误，停止**，不解释为机制效应。
（这条同时证明"候选臂与对照臂的差别只是重建任务"。）

**门 1 — 候选 vs 配对对照**
两个完整开发切分（seed 42 / 3407）上，候选臂的交付配方相对**对照臂**必须**同时为正**。
任一为负 → 停止。**只看目标指标，不看重建损失的高低。**

**门 2 — 增量门槛**
交付配方相对**现任（V12 铁量列 + V7 时长列，即 R2）**的增量 **≥ +0.01**
（用户 2026-09-28 定的工作门槛；铁量列保持 V12 不动，只动时长列）。
不过 → 记为负结果，不封包。

**门 3 — 晋级（沿用既有规则，不放宽）**
≥4 个 split seed、seed 级配对 LCB95 > 0、所有参与 seed 同为正；折级仅作描述。
四个 split 复用同一批标签，LCB 只作切分稳定性指标，不称为四份独立样本的 95% 泛化保证。

**立即停止的三种情况：**
1. 重建学不到超出常数预测的关系（= 门 0a 不过）；
2. 重建变好，但两个完整开发切分的目标指标没有同时改善（= 门 1 不过）；
3. 候选未超过配对对照，或相对现任没有 ≥+0.01 的增量（= 门 1 / 门 2 不过）。

## 7. 参照与判读

- **现任 R2 = V12 铁量列 + V7 时长列**，本地两 seed 均值由同一批 fold 的池化 WMAPE 重算
  （不与不同报告的折均值、池化值或不同配方的分数相加）。
- 平台最佳 `V12_IRON_JOINT_PLR001_A50 = 96.3526`（用户回传，未独立账号核验）。
- **本地幅度不能预报平台幅度**：转移误差是候选相关的，可正可负、已达本地效应的数倍
  （V42 本地 +0.0144 → 平台 −0.0201；N-0048 本地 +0.00975 → 平台 +0.0409）。因此本轮的
  本地增量**只用于排序与定向**，不作平台收益预报。
- 本地 +0.01 ≈ 开发全量 MDE 的 1.3 倍，但只有平台 322 行 MDE（0.0228）的 **0.44 倍**。
  即 +0.01 是"值得试"，不是"平台能可靠分辨"。**不承诺 >96.4。**
