# V2.10 非对称树固定实验

V2.7–V2.9的平滑非线性路线没有超过现有最佳，核参数路线关闭。本轮保留已有效的CatBoost训练方案，检验未使用的非对称树结构：DW为Depthwise、depth6、1500轮、学习率.03、l2=10、min_data_in_leaf=20、RMSE、Plain、MVS、seed42、CPU4线程。每层各叶选择自己的分裂条件。小于20个训练样本的叶不继续寻找分裂；这不是保证每个最终叶至少20个样本。固定结构和叶约束一起比较，不能将差异归因于单独一个参数。

复用NormalizedSnapshotRegressor，训练折均值归一化并还原目标，输入仍21数值加spout_no。已有N1是归一化对称树对照，读取旧OOF不重训。正式参照仍C2铁量/完整B3时长，另报DJ/AORD。固定候选DW与ADW（当前参照/DW原单位等权），不扫描深度、叶样本数、轮数、种子或权重。

复用两组五折，20次真实拟合，全量0。本轮不自动封包；只有每目标入围者在两组都胜过现有最佳，才推进单独发布。分类使用candidate-tiers-v1，正式和探索资格分开；推荐候选2000次配对重采样，不能保证平台提分。多轮使用的开发划分不等于独立确认。

冻结数据/折/参考OOF/旧模型与五个待测包摘要。独立进程回读20模型，核对ID、目标尺度、特征顺序、实际解析参数、树数、反序/分批/单样本仅输入推理、完整OOF/逐折/逐铁口指标与分类。小规模测试非对称树序列化，不占真实拟合预算；运行完整锁定Python3.12测试。

平台最高仍用户回传96.0982，未独立账号核验；原五包顺序不变，用户自行上传。参考：[CatBoost grow_policy及min_data_in_leaf定义](https://catboost.ai/docs/en/references/training-parameters/common)。
