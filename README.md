# Experimental Workspace

Tools for tabular modeling, offline evaluation and reproducible experiments.

The development environment uses Python 3.12 with dependencies pinned in `uv.lock`.

Generated artifacts are kept under `local/` and excluded from version control.

The [2026-09-30 research decision review](docs/research_decision_20260930/REVIEW_AND_PROTOCOL.md)
maps an earlier competition retrospective to this project, records evidence
boundaries, and introduces structurally checked decision cards for future
experiments. These cards do not change frozen model gates or authorize releases.
